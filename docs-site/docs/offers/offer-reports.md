# Offer Reports

## Overview

Offer Reports provide analytics on offer performance, redemption, and impact.


## Key Metrics

### Redemption Metrics
- **Total Redeemed** - Number of times redeemed
- **Redemption Rate** - % of quantity redeemed
- **Unique Customers** - How many customers redeemed
- **Average Value** - Average redemption value

### Financial Metrics
- **Total Discount** - Total value given
- **Revenue Impact** - Impact on revenue
- **ROI** - Return on investment
- **Cost per Redemption** - Cost efficiency


### Performance Over Time
- **Redemption Trends** - Over campaign duration
- **Daily/Weekly/Monthly** - Breakdowns by time period
- **Peak Redemption Times** - When most redeemed
