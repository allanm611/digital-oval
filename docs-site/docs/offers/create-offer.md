# Create Offer

## Overview

The Create Offer workflow guides you through setting up a new promotional offer that can be used in campaigns.

## Creation Steps

**Screenshot:**
[Insert screenshot of create offer form]

### Basic Information
- **Offer Name** - Descriptive name for the offer
- **Description** - Details about the offer
- **Offer Type** - Category of offer (Discount, Free Item, Bundle, etc.)

### Offer Details
- **Discount Amount** - Value or percentage off
- **Quantity Available** - How many can be redeemed
- **Expiration Date** - When offer expires
- **Redemption Limit** - Per customer limit (if applicable)

### Catalog Assignment
- **Select Catalog** - Which catalog to organize under
- **Tags** - Additional tags for organization

### Save Options
- **Save as Draft** - Complete later
- **Publish** - Make available immediately

---

## Tips

- Use clear, compelling offer descriptions
- Set realistic quantity limits
- Plan expiration dates strategically
- Test offer limits before full deployment
