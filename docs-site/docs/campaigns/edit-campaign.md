# Edit Campaign

## Overview

After creating a campaign, you can edit it to modify campaign details, audience configuration, offer assignments, or scheduling. The edit experience returns you to the same 5-step creation flow where you can update any aspect of your campaign.

---

## When You Can Edit

You can edit a campaign at any time as long as you have the `campaigns.edit` permission. This allows you to:
- Update campaign details 
- Modify audience, offers, or scheduling
- Address feedback from approvers after rejection
- Continue working on draft campaigns

---

## How to Edit a Campaign

### Starting the Edit

1. Navigate to the campaign you want to edit
2. Click the **three dots menu (⋯)** on the campaign card or campaign details page
3. Select **Edit Campaign** from the dropdown menu
4. You are returned to the campaign creation flow with all your existing data pre-filled

### The Edit Flow

When editing, you return to the same 5-step creation workflow:

**Step 1: Definition**
- Campaign name, description, catalog, and basic metadata
- Objectives, priority, and communication policy
- Budget and schedule dates

**Step 2: Audience Configuration**
- Target segments and campaign type
- Control group and seed list settings
- Segment configuration and mutually exclusive segment options

**Step 3: Offer Configuration**
- Offers assigned to each segment
- Offer creative and delivery settings
- Bucket allocation for A/B and Champion Challenger campaigns

**Step 4: Scheduling**
- Campaign start and end dates/times
- Recurrence patterns and timezone
- Delivery windows and rendering strategy

**Step 5: Preview & Launch**
- Summary of all changes
- Validation checks
- Options to save or submit

### Navigating Steps

- **Next button** - Move forward with validation
- **Back button** - Return to previous step
- **Step indicators** - Click any completed step to jump back and edit

---

## Saving Changes

### Save Options

**Save as Draft**
- Automatically saves your progress
- Campaign remains in current status
- Continue editing later

**Submit for Approval**
- Submits campaign for re-review
- Campaign moves to "Pending Approval" status
- Previous approval is cleared
- Approvers receive notification

**Discard Changes**
- Click back to return without saving
- All unsaved changes are lost
- Returns to campaign details page

---

## Permissions Required

To edit campaigns, you need:
- **campaigns.edit** - Permission to modify campaign details
