# Campaign Communication Policy

## Overview

Campaign Communication Policies define rules and restrictions for how, when, and with what frequency you can communicate with customers across different communication channels (SMS, Email, USSD, Push notifications).

These policies help ensure:
- **Compliance** - Respect DND (Do Not Disturb) regulations and customer preferences
- **Optimal engagement** - Send messages at appropriate times with appropriate frequency
- **VIP handling** - Apply special rules for valuable customers
- **Channel consistency** - Maintain communication standards across SMS, Email, USSD, and Push

## Accessing Campaign Communication Policies

1. Navigate to **Configuration** from the main menu
2. Select **Campaign Communication Policy**
3. The system displays all configured policies in a table view

## Policy List Features

### Search & Filter
- Use the search field to find policies by name or description
- Search is performed in real-time as you type
- Filter results appear instantly

### Display Columns

Each policy row shows:
- **Policy Name** - The policy identifier and brief description
- **Channels** - Which communication channels this policy applies to (SMS, Email, USSD, Push)
- **Type** - The policy type configuration summary
- **Status** - Active or Inactive badge
- **Actions** - Edit and Delete buttons

### Policy Types

Policies can configure multiple types of rules:

#### Time Window
- Specifies when messages can be sent
- Example: "08:00 AM - 10:00 PM"
- Prevents sending during specific hours

#### Maximum Communication
- Limits message frequency
- Example: "Max 5 per day"
- Options: per hour, per day, per week

#### DND (Do Not Disturb)
- Respects customer's DND preferences
- Manages multiple DND categories
- Prevents unwanted communications

#### VIP List
- Special handling for high-value customers
- Custom priority levels
- Action: Priority delivery or delayed delivery

### Available Actions

For each policy, you can:
- **Edit** - Modify policy rules and channels
- **Delete** - Remove the policy (with confirmation)
- **View Details** - Click policy name to see full configuration

## Policy Status

- **Active** - Policy is currently in use and enforced
- **Inactive** - Policy exists but is not applied to campaigns

## Creating Your First Policy

If no policies exist, you'll see an empty state with:
- Message: "No communication policies created yet"
- **Create Policy** button to start adding policies

## Best Practices

- Create policies for each business line or market segment
- Test policies on small campaigns before wide deployment
- Document the purpose of each policy
- Review and update policies regularly to match changing regulations
- Use clear, descriptive names for easy identification
