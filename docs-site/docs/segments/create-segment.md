# Create Segment

## Overview

Create custom customer segments based on attributes, behaviors, and preferences to target specific audiences in campaigns.

---

## Creation Steps

**Screenshot:**
[Insert screenshot of segment builder]

### Basic Information
- **Segment Name** - Descriptive name
- **Description** - Segment purpose
- **Catalog** - Assign to catalog

### Segment Criteria
- **Conditions** - Define segment rules
  - Demographic (Age, Location, etc.)
  - Behavioral (Purchase history, activity)
  - Transactional (Value, frequency)
- **Logic** - AND/OR conditions
- **Filter Options** - Advanced filtering

### Audience Size
- **Preview** - See estimated audience size
- **Verify** - Check segment is correct

### Save Options
- **Save as Draft** - Finish later
- **Publish** - Make available for campaigns

---

## Condition Types

- **Equals** - Exact match
- **Contains** - Partial match
- **Greater Than** - Numeric comparison
- **Between** - Range matching
- **Is Empty** - Null values

---

## Tips

- Start with simple conditions
- Use descriptive names
- Preview before publishing
- Test with small audiences first
