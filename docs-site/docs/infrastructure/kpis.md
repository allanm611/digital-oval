# KPIs

## Overview

KPIs (Key Performance Indicators) are measurable values that track business performance across campaigns, offers, segments, and customer interactions. Each KPI aggregates data from connection profiles and calculations to provide actionable insights for decision-making.

## Key Features

### KPI Management
- Create and manage multiple KPIs
- Define calculation logic and data sources
- Support for various metric types and aggregation methods
- Monitor KPI values over time

### Data Sources
- Pull data from connection profiles
- Aggregate across dimensions (time, geography, segment)
- Support for custom calculations
- Real-time and historical tracking

### Metric Types
- **Count** - Total count of events/records
- **Sum** - Aggregate numeric values
- **Average** - Calculate mean values
- **Percentage** - Track percentage changes
- **Ratio** - Compare two metrics
- **Custom** - User-defined calculations

### Performance Tracking
- Historical metric values
- Trend analysis capabilities
- Period-over-period comparisons
- Alert thresholds for anomalies

### Compliance & Governance
- Data classification for KPIs
- PII sensitivity tracking
- GDPR compliance indicators
- Audit logging of KPI changes

## KPI Types

### Campaign KPIs
- Campaign reach and impressions
- Engagement and conversion rates
- Response rates by channel
- Campaign ROI and spend

### Offer KPIs
- Offer acceptance rates
- Redemption rates
- Offer performance by segment
- Offer lifetime value

### Segment KPIs
- Segment size and growth
- Segment engagement metrics
- Segment performance indicators
- Active vs inactive ratios

### Customer KPIs
- Customer acquisition cost (CAC)
- Customer lifetime value (CLV)
- Churn rate and retention
- Engagement frequency

## KPI Components

### Basic Configuration
- KPI name and code
- Display name and description
- Measurement unit

### Data Source
- Connection profile selection
- Data entity or table reference
- Column mappings for metrics

### Calculation
- Aggregation method (count, sum, average, etc.)
- Filter conditions
- Grouping dimensions

### Time Period
- Measurement interval (daily, weekly, monthly)
- Retention period for historical data
- Refresh frequency

## Available Actions

- **View Details** - See KPI configuration
- **Create KPI** - Add new metric
- **Edit KPI** - Modify settings
- **View Reports** - Analytics and trends
- **Deactivate** - Disable KPI temporarily
- **Delete** - Remove KPI
