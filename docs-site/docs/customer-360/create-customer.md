# Create Customer

## Overview

Add new customers to your system to build your customer database and enable targeted campaigns and communications.


## Creating a Customer

### Step 1: Basic Information
**Enter required customer details:**
- **First Name** - Customer's first name
- **Last Name** - Customer's last name
- **Email** - Primary email address
- **Phone** - Contact phone number

### Step 2: Account Details
**Configure customer account settings:**
- **Customer ID** - Unique identifier
- **Status** - Active, inactive, or blocked
- **Tier** - Customer tier (if applicable)
- **Source** - How customer was acquired

### Step 3: Preferences

- **Email Opt-in** - Allow email communications
- **SMS Opt-in** - Allow SMS communications
- **Push Opt-in** - Allow push notifications

## Saving the Customer

### Options:
- **Save** - Create customer and return to list
- **Save & Add Another** - Create and start new form

## Best Practices

1. **Verify Email** - Ensure valid email addresses
2. **Set Preferences** - Capture opt-in status correctly
3. **Use Consistent Format** - Follow naming conventions
4. **Complete Profile** - Fill required fields
5. **Review Before Saving** - Double-check information
