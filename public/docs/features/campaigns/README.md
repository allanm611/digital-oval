# Campaigns

Campaigns are the core feature of Sentra CVM, allowing you to create, manage, and execute targeted marketing initiatives.

## Overview

A campaign in Sentra CVM is a coordinated set of marketing actions designed to achieve specific business objectives. Campaigns can include:

- Email communications
- SMS messages
- Push notifications
- In-app messages
- Web experiences
- Targeted offers

## Key Features

### Campaign Creation

- Simple campaign builder interface
- Pre-built campaign templates
- Drag-and-drop workflow design
- Multi-channel messaging support

### Audience Targeting

- Segment-based targeting
- Advanced filtering options
- Dynamic audience rules
- Real-time audience updates

### Campaign Execution

- Scheduled delivery
- Immediate send options
- A/B testing capabilities
- Progressive rollout features

### Performance Tracking

- Real-time analytics
- Conversion tracking
- Revenue attribution
- ROI measurement

## Campaign States

Campaigns move through several states during their lifecycle:

- **Draft** - Campaign is being created and configured
- **Scheduled** - Campaign is scheduled for a future date
- **Active** - Campaign is currently running
- **Paused** - Campaign is temporarily stopped
- **Completed** - Campaign has finished

## Getting Started

1. Navigate to **Campaigns** from the main menu
2. Click **Create Campaign**
3. Choose a template or start from blank
4. Configure campaign settings and audience
5. Design your messaging content
6. Set objectives and metrics
7. Schedule or activate the campaign
8. Monitor performance in real-time
