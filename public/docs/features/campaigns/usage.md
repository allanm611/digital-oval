# Campaigns - Usage Guide

Complete step-by-step guide for creating and managing campaigns in Sentra CVM.

## Creating Your First Campaign

### Step 1: Access the Campaigns Section

1. Log in to Sentra CVM
2. Click **Campaigns** in the main navigation
3. Click the **Create Campaign** button

### Step 2: Basic Campaign Settings

1. Enter a **Campaign Name** (e.g., "Spring Sale 2026")
2. Choose **Campaign Type**:
   - Email Campaign
   - SMS Campaign
   - Multi-channel Campaign
   - Promotional Campaign
3. Set **Campaign Duration**:
   - Start date
   - End date
4. Click **Next**

### Step 3: Define Audience

1. Choose your **Target Audience**:
   - Select existing segments
   - Create new filters
   - Upload customer list
2. Preview audience size
3. Click **Next**

### Step 4: Design Content

1. Choose your **Template** or start blank
2. **For Email Campaigns:**
   - Add subject line
   - Design email content
   - Add personalization variables
   - Include call-to-action
3. **For SMS Campaigns:**
   - Write SMS message (under 160 characters)
   - Add personalization
   - Include landing page link
4. Preview the content
5. Click **Next**

### Step 5: Set Objectives & Scheduling

1. Add **Campaign Objectives** (what you want to measure)
2. Choose **Delivery Method:**
   - Immediate send
   - Scheduled send (date and time)
   - Progressive rollout (% per day)
3. Select **timezone** for scheduling
4. Click **Review**

### Step 6: Review & Launch

1. Review all campaign settings
2. Run a **Test Send** (optional)
3. Click **Activate** to launch
   - Or click **Schedule** for future date

## Managing Active Campaigns

### Pause a Campaign

1. Go to **Campaigns** list
2. Find your active campaign
3. Click the **Pause** button
4. Confirm the pause action

### Resume a Campaign

1. Find a paused campaign
2. Click **Resume**
3. Campaign continues from where it stopped

### View Campaign Performance

1. Click on campaign name to open details
2. View **Analytics** tab:
   - Send count
   - Open rate
   - Click rate
   - Conversion rate
   - Revenue generated

### Edit Campaign Settings

1. Open campaign details
2. Click **Edit** button
3. Update desired settings
4. Note: Cannot edit audience for active campaigns
5. Click **Save**

## Troubleshooting

### Campaign Won't Activate

- Check audience size is not empty
- Ensure all required fields are filled
- Verify campaign duration is in the future

### Low Performance Metrics

- Review targeting rules
- Check message content quality
- Consider A/B testing different versions
- Adjust send time for better engagement

### Audience Size Mismatch

- Re-run audience calculation
- Check segment filters
- Verify audience data is current

## Tips & Best Practices

- **Start Small** - Test with 10% of audience first
- **A/B Test** - Split audience to test variations
- **Monitor Closely** - Check performance daily
- **Optimize** - Use learnings to improve future campaigns
- **Document Results** - Track what worked and what didn't
- **Segment Well** - More targeted = better results
- **Clear CTAs** - Use compelling calls-to-action
- **Mobile Friendly** - Ensure content works on mobile
