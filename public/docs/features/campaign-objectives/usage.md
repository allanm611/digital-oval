# Campaign Objectives - Usage Guide

This guide walks you through using Campaign Objectives in Sentra CVM.

## Creating Campaign Objectives

### Step 1: Access Campaign Details

1. Go to **Campaigns** from the main menu
2. Select an existing campaign or create a new one
3. Click the **Objectives** tab

### Step 2: Add New Objective

1. Click **Add Objective** button
2. Fill in the objective details:
   - **Name** - Clear, descriptive name for the objective
   - **Type** - Select from predefined types (Awareness, Consideration, Conversion, etc.)
   - **Target Metric** - Choose what you want to measure
   - **Target Value** - Set the goal (e.g., 10,000 conversions, 50% engagement rate)
   - **Timeline** - Set start and end dates

3. Click **Save**

## Managing Objectives

### Viewing Progress

- The **Progress** column shows real-time performance
- Color indicators show status:
  - **Green** - On track to meet target
  - **Yellow** - At risk of not meeting target
  - **Red** - Behind target

### Updating Objectives

1. Click on any objective to edit
2. Update the details as needed
3. Click **Save** to apply changes

### Tracking Performance

- Monitor actual values against targets
- View historical performance data
- Export reports for analysis

## Examples

**Objective Name:** Spring Campaign Brand Awareness
- **Type:** Awareness
- **Target Metric:** Impressions

- **Timeline:** March 1 - April 30, 2026

### Example 2: Conversion Objective

**Objective Name:** Product Launch Conversions

## Tips

- Start with 1-3 key objectives per campaign
- Use SMART goals for better tracking
- Review objectives weekly
- Adjust targets based on performance data
- Share objectives with team members for alignment
