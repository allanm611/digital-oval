# System Events List

System Events List shows KPI definitions based on operational/system event signals.

![System Events List](/img/infrastructure/systemeventsallpage.png)

## What This Page Is For

- browse event-driven KPI definitions
- review metrics used for operational segmentation logic
- identify missing event metrics that need to be added

## What The List Columns Mean

- **Name**: event KPI label shown in condition pickers.
- **Description**: what operational signal the KPI captures.
- **Field Type**: value type and operator compatibility.
- **Category**: confirms grouping under System Events.
- **Source Table / Data Source**: where event values are read from.
- **Frequency**: how quickly event updates are expected to propagate.
