# Job Workflow Steps Analytics

Job Workflow Steps Analytics helps identify problematic steps and execution bottlenecks.

## Typical Metrics

- step success/failure concentration
- retry-heavy steps
- slowest step types
- parallel group performance characteristics

![Job workflow step analytics stat cards](/img/v1.0/jobmanagement-images/jobworkflowstepanalyticsstatcards.png)

![Job workflow steps analytics step type graph](/img/v1.0/jobmanagement-images/jobworkflowstepsanalyticsstetypegrapgh.png)

## How To Use It

- isolate high-failure steps for remediation
- optimize timeout/retry for slow steps
- improve sequencing and dependency design
