# Scheduled Jobs Analytics

Scheduled Jobs Analytics provides aggregate visibility into job health and schedule quality.

## Typical Metrics

- total jobs and active/draft counts
- SLA breach indicators
- stale jobs and due-for-execution counts
- owner/type distribution summaries

## How To Use It

- monitor operational risk before incidents escalate
- identify job categories with repeated misses
- track health changes after schedule or timeout tuning
