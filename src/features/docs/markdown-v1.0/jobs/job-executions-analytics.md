# Job Executions Analytics

Job Executions Analytics focuses on execution outcomes, reliability trends, and performance timing.

## Typical Metrics

- success/failure/timeout distribution
- average and peak duration
- long-running and retried execution trends
- SLA and completion-rate signals

![Job execution analytics status and trigger](/img/v1.0/jobmanagement-images/jobexecutionanalyticsstatusandtriggerimage.png)

![Job execution analytics SLA, execution health score, and resource utilization](/img/v1.0/jobmanagement-images/jobexecutionanalyticsslaandexecutionhealthscoreandresourceutlizationimage.png)

## How To Use It

- compare behavior before and after configuration changes
- identify regression windows by time
- prioritize jobs needing retry/timeout policy tuning
