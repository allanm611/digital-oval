# Job Workflows List

Job Workflows List is the table view for workflow records.

## Table Fields

- Name
- Description
- Type
- Status
- Created / Updated context

## Filters

Search by name/description and filter by workflow status and type.

## Actions

- Create
- View
- Edit
- Delete
- clone/activate/deactivate actions where available
