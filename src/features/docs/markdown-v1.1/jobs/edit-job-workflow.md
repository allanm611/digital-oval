# Edit Job Workflow

Edit Job Workflow uses the same fields as create, with existing values prefilled.

This route (`/dashboard/workflows/:id/edit`) reuses the Create Job Workflow page component.

## Common Updates

- naming/description clarity
- workflow type
- active state

![Job workflow details (edit context)](/img/v1.1/jobmanagement-images/jobworkflowdetailimage2.png)

## Save Behavior

Changes are validated and saved to the existing workflow record.
