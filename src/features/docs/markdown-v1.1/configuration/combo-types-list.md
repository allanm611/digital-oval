# Combo Type List

The Combo Types list view shows all defined combo type templates with quick access to manage them.

![Combo Types List](/img/v1.1/configuration/combotypeslist.png)

## Accessing the List

**Navigation:** Configuration → Combo Types

## List Columns

**Combo Type Name** - The name of the combo type template

**Description** - Summary of the combo type's purpose and usage

**Status** - Active or Inactive status

**Resources** - Shows which resources are configured (Data, Voice, SMS)

**Actions** - Available management actions

## Search and Filtering

Use the **Search** field to find combo types by:
- Combo type name
- Description

## Action Buttons

Each combo type row has the following actions:

**Edit** - Opens the edit form to modify the combo type configuration

**View Details** - Opens the [Combo Type Details](/documentation/configuration/view-combo-type) page

**Delete** - Removes the combo type (requires confirmation)

## Create New Combo Type

Click the **Create** button in the top right to open the combo type creation form.

See [Create a Combo Type](/documentation/configuration/create-combo-type) for detailed steps.

## Empty State

If no combo types exist, the list shows a message prompting you to create the first combo type.

## Tips

- Use descriptive names for combo types to indicate the bundle composition
- Keep descriptions updated to explain what services and quantities the combo includes
- Monitor active status to ensure combo types used in products are not deactivated
- Delete unused combo types to keep the catalog clean and organized
