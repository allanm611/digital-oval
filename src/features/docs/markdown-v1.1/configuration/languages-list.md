# Language List

View all available languages and manage language support for your campaigns and content.

![Languages List](/img/v1.1/configuration/languageslistimage.png)

## Accessing the List

**Navigation:** Configuration → Languages

## List Columns

**Language Name** - The readable name of the language (e.g., "English", "Spanish")

**Description** - Additional context about the language variant

**Language Code** - The standard language identifier (e.g., "en", "es", "fr")

**Country** - The region or country this language variant is for

**Status** - Active or Inactive

**Actions** - Available management actions

## Using This View

Use this view to:
- Quickly confirm whether a language is active and available for content configuration
- See all supported languages at a glance
- Identify which language codes are in use
- Verify regional variants are configured correctly

## Search and Filtering

Use the **Search** field to find languages by:
- Language name
- Description
- Language code

This is helpful when you have many languages configured.

## Action Buttons

Each language row has the following actions:

**Edit** - Opens the form to modify the language

**View Details** - Opens the [Language Details](/documentation/configuration/view-language) page

**Delete** - Removes the language (requires confirmation)

## Create New Language

Click the **Create** button in the top right to open the language creation form.

See [Create a Language](/documentation/configuration/create-language) for detailed steps.

## Empty State

If no languages exist, the list shows a message prompting you to create the first language.

## Tips

- Create all language variants your customers need before launching campaigns
- Use standard language codes so team members recognize them
- Keep descriptions updated to indicate the target region or audience
- Monitor active languages to ensure they have the required character sets
- Delete unused languages to keep the list organized
