# Utility Configuration

Utility Configuration allows you to define and manage utility types used across the platform. Utilities can represent services, features, or other configurable items that support business operations.

## Accessing Utility Configuration

Navigate to **Configuration → Utility Configuration**.

## What You Can Do

- View all utility types
- Search and filter utility types
- Create a new utility type
- Edit or delete existing utility types

## Utility Type Fields

- **Name** (required)
- **Description** (optional)
- **Active** (checkbox)

## Creating or Editing a Utility Type

1. Click **Create** or **Edit** to open the modal.
2. Fill in the required fields.
3. Click **Save** to apply changes.

## Tips

- Use descriptive names for each utility type.
- Only active utility types are available for use in other modules.
