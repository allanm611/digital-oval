# View Language Details

View complete information about a language including its code, regional configuration, and character set mapping.

## Accessing Language Details

From the [Language List](/documentation/configuration/languages-list):

1. Find the language you want to view
2. Click the **View Details** button (eye icon) on the row

The details page opens showing the complete language configuration.

## Language Information

**Language Name**
- The readable identifier for this language
- Used when selecting languages for content creation

**Description**
- Additional context about the language variant or target audience

**Status**
- Active or Inactive
- Active languages are available for selection when creating content
- Inactive languages are not available for use

## Language Configuration

**Language Code** - The standard identifier (e.g., "en", "es", "fr", "sw")

**Country** - The region or country for this language variant

**Character Set Type** - The encoding standard used for messages in this language
- Determines character limits
- Ensures proper rendering of special characters
- Affects message length and splitting

## Editing

To modify this language:

1. Click the **Edit** button
2. Update the desired fields:
   - Language name
   - Description
   - Language code
   - Country
   - Character set type
   - Status
3. Click **Save** to apply changes

## Deleting

To remove this language:

1. Click the **Delete** button
2. Confirm deletion in the modal
3. The language is permanently removed

**Warning:** Ensure no active creatives or content are using this language before deleting.

## Using This Language

Once created, this language can be:

- Selected when creating creative templates
- Used for campaign content localization
- Referenced when configuring language-specific messaging
- Used across multiple campaigns and offers

## Tips

- Keep language information up to date with current regional focus
- Verify the character set supports all characters needed for the language
- Monitor languages before deactivating to ensure nothing depends on them
- Use consistent language codes across your system
- Create regional variants if you support different dialects
- Test message rendering and character limits before using in live campaigns
