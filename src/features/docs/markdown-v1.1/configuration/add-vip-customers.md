# Add VIP Customers

## Overview

Add customers to VIP lists to segment your high-value customers. You can add customers individually or in batches from the VIP Customers tab.

## Opening the Add Customers Modal

From the **VIP Customers** tab, click the **Add Members** button in the top right.

A modal opens showing available customers to add to VIP lists.

## Adding Customers

### Select VIP List

1. Use the **VIP List** dropdown to select which VIP list to add customers to
2. The dropdown shows all available VIP lists

### Search for Customers

1. Use the search box to find customers by name, email, or phone number
2. The search is performed as you type
3. Results are paginated showing 20 customers per page

### Select Customers

1. Check the checkbox next to each customer you want to add
2. Customers already in VIP lists are filtered out to prevent duplicates
3. You can select multiple customers in the same batch

### Save Selected Customers

1. After selecting customers, click the **Save** button
2. The system will add all selected customers to the chosen VIP list
3. Status will be set to Active automatically
4. Added date and user information are recorded

## Success Message

After adding customers, you'll see a success message confirming:
- Number of customers added
- The operation completed successfully

The VIP Customers list will be updated to show the newly added members.

## Filtering and Status

When adding members:

### Customer Status Filter
Filter available customers by:
- **All Status** - Show all customers
- **Active** - Show active customers
- **Inactive** - Show inactive customers

### Pagination

The customer list is paginated with 20 customers per page. Use the pagination controls to navigate through customer pages.

## Error Handling

If adding customers fails:

- An error message will appear explaining the issue
- Check that:
  - A VIP list is selected
  - At least one customer is selected
  - The customer is not already in the selected VIP list

## Tips

- Use search to quickly find customers by name, email, or phone
- Select multiple customers to add them all at once
- Check the customer status filter if you're looking for specific customer types
- Verify the VIP list selection before saving
- The system prevents duplicate entries automatically
