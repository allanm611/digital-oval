# Authentication

## Overview

Authentication is how you securely access the Sentra CVM platform. Whether you're logging in, creating a new account, or resetting your password, these guides walk you through the authentication process step by step.


## Getting Started

### [Login](/documentation/authentication/login)

Access the platform with your credentials. Learn how to enter your username/email and password, and understand two-factor authentication if enabled.

### [Registration](/documentation/authentication/registration)

Create a new account to access Sentra CVM. Fill in your personal information, set up your credentials, and complete the registration process.

### [Password Reset](/documentation/authentication/password-reset)

Forgot your password? Follow the guided process to reset it and regain access to your account.

### [Landing Page](/documentation/authentication/landing)

Once authenticated, explore the main dashboard and learn how to access all core platform modules from the landing page.


## Quick Start

**New to Sentra CVM?**

1. If you don't have an account yet, go to [Registration](/documentation/authentication/registration)
2. Follow the steps to create your account
3. Once created, use [Login](/documentation/authentication/login) to access the platform
4. Explore the [Landing Page](/documentation/authentication/landing) to navigate modules
5. If you forget your password, use [Password Reset](/documentation/authentication/password-reset)


## Security Tips

- Keep your password secure and don't share it
- Use two-factor authentication if available for added security
- Log out when done, especially on shared computers
- Change your password regularly
- If you suspect unauthorized access, reset your password immediately
