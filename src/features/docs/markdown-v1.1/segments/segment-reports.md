# Segment Reports

## Overview

Segment Reports provide detailed analytics and insights about segment performance, membership trends, and engagement metrics. Use these reports to monitor segment health and make data-driven decisions about segmentation strategies.

![Segment Reports](/img/v1.1/segments-img/segmentreports.png)

## Accessing Segment Reports

From the [Segments List](/documentation/segments/segments-list), click **Reports** to view analytics for all segments, or click **Reports** on a specific segment to view detailed metrics for that segment.

## Report Types

### Segment Overview

**Metrics Displayed:**

- **Total Members** - Current count of customers in the segment
- **New Members (This Week)** - Number of customers added this week
- **Churn Rate** - Percentage of customers who left the segment
- **Average Member Age** - How long members have been in the segment
- **Segment Health** - Overall segment quality indicator

### Membership Trends

**Visualizations:**

- **Membership Over Time** - Line chart showing member count changes
- **New Members Trend** - Trend of new members joining per week/month
- **Churn Trend** - Trend of members leaving the segment
- **Seasonal Patterns** - Identify recurring membership patterns

### Engagement Metrics

**Metrics Tracked:**

- **Campaign Inclusion** - Number of campaigns using this segment
- **Message Engagement Rate** - Percentage of segment members engaging with messages
- **Click-through Rate** - Segment engagement on links
- **Conversion Rate** - Percentage of segment members converting after campaigns
- **Revenue Impact** - Revenue attributed to campaigns using this segment

### Demographic Breakdown

**Analysis:**

- **Member Age Distribution** - Age range distribution of segment members
- **Geographic Distribution** - Location breakdown of segment members
- **Customer Tier Distribution** - Customer class breakdown (e.g., Bronze, Silver, Gold)
- **Channel Preference** - Preferred communication channels for segment members

### Comparison Reports

**Features:**

- **Compare to All Customers** - See how segment metrics differ from overall customer base
- **Compare to Other Segments** - Select 2-3 segments to compare side-by-side
- **Benchmark Performance** - Compare engagement rates to industry benchmarks

## Report Filters and Options

### Date Range

Select custom date ranges to analyze specific periods:

- Last 7 days
- Last 30 days
- Last 90 days
- Last year
- Custom date range

### Export Reports

Download reports in multiple formats:

- **PDF** - Professional report with charts and tables
- **CSV** - Data export for analysis in Excel or other tools
- **Email Report** - Schedule recurring reports to be emailed

### Scheduled Reports

Set up automated report generation:

1. Click **Schedule Report**
2. Select report type and frequency
3. Choose recipients
4. Set delivery time
5. Save

Reports are automatically generated and delivered on schedule.

## Using Segment Reports

### Identify Stale Segments

Look for segments with:

- Declining membership trends
- High churn rates
- Low engagement rates

These segments may need reconfiguration or refreshing.

### Optimize Segment Performance

Use engagement metrics to:

- Identify high-performing segments for increased campaign focus
- Find under-performing segments for refinement
- Test different segment criteria to improve results

### Monitor Segment Health

Regular review of segment reports helps you:

- Ensure segment conditions are still valid
- Track membership stability
- Monitor for data quality issues
- Validate segment refresh schedules

### Plan Campaign Strategy

Use segment insights to:

- Select optimal segments for campaigns
- Identify audience gaps for new segments
- Plan targeting strategy based on engagement data
- Forecast campaign impact

## Tips

- Review segment reports monthly to monitor trends
- Compare segment performance to campaign objectives
- Use benchmark reports to identify opportunities
- Archive or delete segments with no recent campaign usage
- Update segment conditions based on performance insights
