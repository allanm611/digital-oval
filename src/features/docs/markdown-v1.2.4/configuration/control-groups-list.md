# Control Group List

![Control Groups List](/img/v1.1/configuration/universalcontrolgroupslist.png)

## Overview

The Universal Control Group List provides a comprehensive view of all control groups in your system. You can search, filter, and manage your control groups from this page.

## Page Layout

### Header Section
- **Title**: Universal Control Groups
- **Description**: Create and manage control groups to measure campaign effectiveness and customer behavior
- **Create Button**: Click to create a new control group

### Statistics Cards
The page displays three statistics cards showing:
- **Total Groups**: Total number of control groups in the system
- **Active Groups**: Number of currently active control groups
- **Total Members**: Total number of members across all control groups

## Search and Filtering

### Search
Use the search box to find control groups by name or description. The search is performed as you type.

### Filters
Click the **Filters** button or use the status dropdown to filter by:
- **All Status** - Show all control groups
- **Active** - Show only active control groups
- **Inactive** - Show only inactive control groups

## Control Group List

The control group list displays the following information for each group:

**Name** - Control group identifier

**Status** - Shows Active or Inactive state

**Type** - Control group type

**Percentage** - Percentage of audience in the group

**Members** - Number of customers in the group

**Customer Base** - Source type: Active Subscribers, All Customers, or Custom Conditions

**Recurrence** - Generation frequency: One-time, Daily, Weekly, or Monthly

## Actions

### View Details
Click the **View** icon (eye) to open the control group details page to see full configuration and members.

### Edit
Click the **Edit** icon (pencil) to modify the control group configuration.

### Delete
Click the **Delete** icon (trash) to remove a control group. You'll be asked to confirm the deletion.

## Pagination

If there are many control groups, the list is paginated with 10 control groups per page. Use the pagination controls at the bottom to navigate between pages.

## Tips

- Use the status filter to focus on active control groups
- Search by name to quickly find specific control groups
- Check the Percentage column to see member distribution
- Monitor Member Count to understand control group sizes
- Check Recurrence to understand generation schedules
