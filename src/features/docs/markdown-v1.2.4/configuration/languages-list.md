# Languages List

## Overview

The Languages List page displays all supported languages in the system, allowing you to manage multi-language support for your campaigns and content.

![Languages List](/img/v1.1/configuration/languageslist.png)

## Managing Languages

Navigate to **Configuration → Languages** to view and manage all languages.

### View Languages List

The languages list displays all configured languages with:

- **Language Name** - Readable name of the language
- **Language Code** - ISO 639-1 code (e.g., "en", "es", "fr")
- **Country** - Country or region for this language variant
- **Character Set** - Character set type supporting this language
- **Status** - Active or Inactive
- **Created Date** - When the language was created

You can:

- **Search** - Find languages by name or code
- **Filter by Status** - Show all, active, or inactive languages

## Actions

### Create Language

Click the **Create** button to add a new language.

For detailed instructions, see [Create a Language](/documentation/configuration/create-language).

### Edit Language

Click **Edit** on any language to update:

- Language name
- Description
- Character set type
- Status

Click **Save** to apply changes.

### Delete Language

Click **Delete** to remove a language from the system. The language will be permanently removed and cannot be recovered.

## Tips

- Create all required language variants before launching multi-language campaigns
- Use standard ISO language codes for consistency
- Ensure the selected character set supports all characters in the language
- Test content rendering in each language to verify character set compatibility
- Coordinate with your content and localization teams on which languages to support
