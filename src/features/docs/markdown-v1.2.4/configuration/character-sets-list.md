# Character Set List

View all available character sets and manage character encoding for your messages.

![Character Sets List](/img/v1.1/configuration/charactersetslistimage.png)

## Accessing the List

**Navigation:** Configuration → Character Sets

## List Columns

**Character Set Name** - The identifier for this character set

**Description** - Summary of the character set's encoding and usage

**Message Type** - The category this character set is used for (SMS, Email, etc.)

**Character Set Type** - The encoding standard (e.g., GSM 7-bit, Unicode)

**Status** - Active or Inactive

**Actions** - Available management actions

## What Makes It Easier

The list makes it easier to:
- Verify what is active before mapping languages and creative content
- See which encoding types are configured
- Understand character limit handling for different message types

## Search and Filtering

Use the **Search** field to find character sets by:
- Character set name
- Description

## Action Buttons

Each character set row has the following actions:

**Edit** - Opens the form to modify the character set

**View Details** - Opens the [Character Set Details](/documentation/configuration/view-character-set) page

**Delete** - Removes the character set (requires confirmation)

## Create New Character Set

Click the **Create** button in the top right to open the character set creation form.

See [Create a Character Set](/documentation/configuration/create-character-set) for detailed steps.

## Empty State

If no character sets exist, the list shows a message prompting you to create the first character set.

## Tips

- Keep character set definitions aligned with your messaging provider's requirements
- Test character limit calculations with actual content before going live
- Use consistent naming to clearly indicate the encoding type
- Monitor active character sets to ensure they match your current languages and channels
- Review character sets when adding support for new languages or character types
