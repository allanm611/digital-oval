# DND Management

## Overview

DND (Do Not Disturb) Management allows you to manage customer opt-outs across multiple communication channels. You can add customers to DND lists for specific message types to exclude them from receiving those messages.

DND Management provides two main workflows:
- **By Channel** - Manage DND for individual communication channels (SMS, Email, USSD, Push)
- **Bulk Management** - Manage DND subscriptions across all channels with advanced filtering and batch operations

## What is DND Management?

![DND Management Main Page](/img/v1.2.4/dndmanagementmainpage.png)

DND Management allows you to:

- **Manage Opt-Outs** - Add customers to Do Not Disturb lists
- **Track Preferences** - Monitor which customers have opted out  
- **Support Multiple Channels** - Manage DND across SMS, Email, USSD, and Push Notifications
- **Filter by Message Type** - Exclude customers from specific message categories (Promotional, Transactional, Marketing, Service, Other)
- **Bulk Operations** - Add and remove multiple customers at once

## DND Message Types

All DND subscriptions are categorized by message type:

- **Promotional** - Special offers, discounts, promotional campaigns
- **Transactional** - Order confirmations, receipts, transaction-related communications
- **Marketing** - Marketing campaigns and brand communications
- **Service** - Service updates, maintenance notifications, account information
- **Other** - Miscellaneous communications that don't fit other categories

## DND Management Options

**[DND Management by Channel](/documentation/configuration/dnd-management-by-channel)** - Manage DND lists for individual communication channels, add/remove customers one at a time.

**[DND Management Bulk](/documentation/configuration/dnd-management-bulk)** - Manage DND subscriptions across all channels with search, filtering, and batch operations.
