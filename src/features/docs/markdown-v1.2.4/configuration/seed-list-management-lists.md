# Manage Seed Lists

## Overview

The Seed Lists tab allows you to create, view, and manage seed list definitions. Seed lists organize your test recipients into separate groups for different testing purposes.

## Accessing Seed Lists

1. Go to **Configuration → Seed List Management**
2. Click the **Seed Lists** tab to view all seed lists

The Seed Lists tab displays all seed lists in your system with the following information:

**List Name** - Name of the seed list

**Description** - Optional description of the seed list's purpose

**Recipient Count** - Number of recipients in this seed list (clickable to view members)

**Status** - Processing status of list operations:
- **Pending** - List creation is queued
- **Processing** - List operations are in progress
- **Completed** - List operations finished successfully
- **Failed** - List operations encountered errors

**Actions** - Delete button to remove the seed list

## Search and Filtering

### Search

Use the search box to find seed lists by name or description. The search is performed as you type.

## Creating a Seed List

Click the **Create List** button in the top right:

1. A modal opens with form fields
2. Enter the **List Name** (required)
3. Enter an optional **Description**
4. Click **Create** to add the seed list

The new seed list will appear in the table and be ready to receive members.

## Viewing List Members

Click on the **recipient count** for any seed list to open a modal displaying all members in that list:

1. The modal shows a table of all recipients in the selected seed list
2. View recipient details including name, email, phone, and status
3. Click **Remove** on any recipient to remove them from the seed list
4. Close the modal to return to the seed lists view

## Deleting a Seed List

To remove a seed list:

1. Click the **Delete** button (trash icon) on the seed list row
2. Confirm the deletion when prompted
3. The seed list and its recipients will be removed from the system

**Note**: Deletion cannot be undone. Ensure the list is no longer needed before deleting.

## Tips

- Use descriptive names for seed lists to indicate their purpose or team
- Keep descriptions updated to explain the testing context
- Monitor recipient counts to understand test coverage
- Regularly review and clean up inactive seed lists
