# Resource Types Configuration

Resource Types allow you to define and manage the different types of resources available in the system. These are used to classify and organize resources for offers, products, and other modules.

## Accessing Resource Types

Navigate to **Configuration → Resource Types**.

![Resource Type List](/img/v1.1/configuration/resourcetypelist.png)

The resource types table displays these columns:

- **Name**
- **Value (Key)**
- **Category**
- **Unit**
- **Description**
- **Status** (Active/Inactive)
- **Actions** (Edit/Delete)

## What You Can Do

- View all resource types
- Search and filter resource types
- Create a new resource type
- Edit or delete existing resource types

## Resource Type Fields

- **Name** (required)
- **Description** (optional)
- **Resource Key** (required, unique)
- **Active** (checkbox)

## Creating or Editing a Resource Type

1. Click **Create** or **Edit** to open the modal.

![Create Resource Type Modal](/img/v1.1/configuration/createresourcetype.png)

2. Fill in the required fields.
3. Click **Save** to apply changes.

## Tips

- Use clear names and descriptions for each resource type.
- Only active resource types are available for selection in other modules.
