# Creative Template List

View all available creative templates and manage your template library.

![Creative Templates List](/img/v1.1/configuration/creativetemplatelistimage.png)

## Accessing the List

**Navigation:** Configuration → Creative Templates

## List Columns

**Template Name** - The identifier for this creative template

**Description** - Summary of the template's purpose and usage

**Channel** - The communication channel the template is designed for (SMS, Email, Push, etc.)

**Locale** - The language and region for this template variant

**Status** - Active or Inactive

**Actions** - Available management actions

## Search and Filtering

Use the **Search** field to find templates by:
- Template name
- Description

This is helpful when your template library grows.

## Action Buttons

Each template row has the following actions:

**Edit** - Opens the form to modify the template

**View Details** - Opens the [Creative Template Details](/documentation/configuration/view-creative-template) page

**Delete** - Removes the template (requires confirmation)

## Create New Template

Click the **Create** button in the top right to open the template creation form.

See [Create a Creative Template](/documentation/configuration/create-creative-template) for detailed steps.

## Empty State

If no templates exist, the list shows a message prompting you to create the first creative template.

## Tips

- Use descriptive names that indicate the template purpose and channel
- Keep descriptions clear so other team members understand when to use each template
- Create multiple locale variants for the same template when supporting multiple languages
- Monitor template status to ensure active templates are being used
- Archive or delete old templates to keep the library organized
