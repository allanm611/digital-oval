# Combo Types List

View all defined combo type templates with quick access to manage them.

![Combo Types List](/img/v1.1/configuration/combotypeslistpage.png)

**Navigation:** Configuration → Combo Types

## List Columns

**Name** - The name of the combo type

**Description** - Summary of the combo type

**Status** - Active or Inactive

**Actions** - Edit, View Details, Delete

## Search

Use the **Search** field to find combo types by name or description.

## Actions

**Edit** - Opens the edit form to modify the combo type

**View Details** - Opens the details page showing the complete configuration

**Delete** - Removes the combo type (requires confirmation)

## Create New Combo Type

Click the **Create** button to open the creation form.

See [Create a Combo Type](/documentation/configuration/create-combo-type) for detailed steps.
