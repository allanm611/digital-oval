# View Creative Template Details

View complete information about a creative template including its content, channel, and locale settings.

## Accessing Template Details

From the [Creative Template List](/documentation/configuration/creative-templates-list):

1. Find the template you want to view
2. Click the **View Details** button (eye icon) on the row

![Creative Template Details](/img/v1.1/configuration/creativetemplatedetailsimage.png)

The details page opens showing the complete template configuration and content.

## Template Information

**Template Name**

- The identifier for this creative template
- Used when referencing the template in campaigns and offers

**Description**

- Summary of the template's purpose and when to use it

**Status**

- Active or Inactive
- Active templates are available for selection when building creatives
- Inactive templates are not available for use

## Channel and Locale

**Channel** - The communication method this template is designed for:

- SMS
- Email
- Push Notification
- Other messaging channels

**Locale** - The language and regional variant for the content

## Template Content

View the actual content configured for this template:

**For SMS:**

- Message text
- Character count
- Dynamic variables used

**For Email:**

- Subject line
- Message body
- HTML formatting (if applicable)

**For Push:**

- Title
- Message body
- Action or deep link

## Editing

To modify this template:

1. Click the **Edit** button
2. Update the desired fields:
   - Template name
   - Description
   - Channel
   - Locale
   - Content
3. Click **Save** to apply changes

## Deleting

To remove this template:

1. Click the **Delete** button
2. Confirm deletion in the modal
3. The template is permanently removed

**Warning:** Ensure no active creatives are using this template before deleting.

## Using This Template

Once created, this template can be:

- Referenced when creating offer creatives
- Used as a starting point for campaign messaging
- Shared across teams for content consistency
- Duplicated for creating similar templates in other locales

## Tips

- Review template content regularly to ensure messaging is current
- Keep descriptions updated as usage changes
- Use consistent variable names for easy reference
- Monitor templates before deactivating to ensure nothing depends on them
- Create locale variants for all languages you support
