# Programs Overview

Programs represent initiatives or customer engagement frameworks within your organization. They help organize campaigns and group related business activities.

## What are Programs?

Programs allow you to:
- **Organize Campaigns** - Group campaigns under specific programs
- **Assign Ownership** - Campaigns can be assigned to programs
- **Track Initiatives** - Group related business initiatives together

## Managing Programs

Navigate to **Configuration → Programs** to manage all programs.

![Programs List](/img/v1.1/configuration/programslist.png)

### Create Program

Click the **Create** button to add a new program.

![Create Program](/img/v1.1/configuration/createprogram.png)

**Required Fields:**
- **Program Name** - The name of the program (max 100 characters)
- **Program Code** - Unique code identifier for the program

**Optional Fields:**
- **Description** - Additional details about the program (max 500 characters)
- **Program Type** - Category or type of program
- **Start Date** - When the program begins
- **End Date** - When the program ends
- **Budget Total** - Total budget allocated to the program

Click **Save** to create the program.

### Edit Program

Click **Edit** on any program to update:
- Program Name
- Program Code
- Description
- Program Type
- Start Date
- End Date
- Budget Total
- Active Status

Click **Save** to apply changes.

### Delete Program

Click **Delete** to remove a program. The program will be permanently removed from the system.

## Using Programs in Campaigns

When creating a campaign:

1. Go to **Create Campaign** → **Step 1: Definition**
2. Select **Program** from the dropdown
3. Search by program name to find the program
4. Select the program that this campaign belongs to
5. Continue with campaign configuration

The assigned program helps:
- Organize which initiative the campaign is part of
- Group campaigns together
- Clarify program ownership
