# Creative Templates Overview

Creative Templates are reusable content definitions used when teams build offer creatives. They help keep messaging consistent while still allowing channel-specific and language-specific content.

## Accessing Creative Templates

**Navigation:** Configuration → Creative Templates

From the main Configuration page, Creative Templates is available as a dedicated section.

## What You Can Do

- View existing creative templates in a list
- Create new template records
- Edit existing templates
- Delete templates that are no longer needed
- Search by name or description

## Why Teams Use This Page

This page is mainly for content governance. Teams maintain template records so campaign builders do not have to start from scratch every time.

Typical uses:

- Standardize naming and template structure
- Keep descriptions clear for cross-team handover
- Provide a reusable base during offer creative setup
- Ensure brand consistency across channels

## Key Concepts

**Template** - A reusable content blueprint that can be used across multiple offers and creatives

**Channel** - The medium through which the creative will be delivered (SMS, Email, Push, etc.)

**Locale** - The language and regional variant for the template content

**Status** - Whether the template is active and available for use
