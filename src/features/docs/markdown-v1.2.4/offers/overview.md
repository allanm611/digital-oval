# Offers

## Overview

The Offers section is your hub for managing all customer offers and promotional deals. Create, configure, and track offers that you can assign to campaigns and deliver to customer segments.

## Key Features

- **Offer Management** - Create and manage promotional offers
- **Offer Catalogs** - Organize offers into catalogs
- **Performance Tracking** - Monitor offer performance and redemption
- **Campaign Integration** - Assign offers to campaigns
- **Search & Filter** - Quickly find offers


## Getting Started

### Creating an Offer
To create a new offer, see the [Create Offer](/documentation/offers/create-offer) guide for a complete step-by-step walkthrough.

### Viewing Offer Details
To view, manage, and track individual offers, see [View Offer Details](/documentation/offers/view-offer-details).

### Monitoring Performance
To track offer performance and redemption metrics, see [Offer Reports](/documentation/reports/offer-reports).

### Offer Catalogs
To organize offers into catalogs, see [Offer Catalog](/documentation/offers/offer-catalog).


## Offer Status

- **Draft** - Offer being created
- **Active** - Offer available for campaigns
- **Paused** - Temporarily disabled
- **Archived** - Old offers for reference
- **Expired** - Offer end date passed


## Quick Start

**New to offers?**

1. Go to [Create Offer](/documentation/offers/create-offer) to set up a new promotional offer
2. [View Offer Details](/documentation/offers/view-offer-details) to manage and track your offers
3. Check [Offer Reports](/documentation/reports/offer-reports) to monitor performance
4. Organize offers using [Offer Catalogs](/documentation/offers/offer-catalog)
