# Settings

## Overview

Settings allows you to configure your personal preferences for the platform. You can customize your location, language, timezone, date and currency formats, communication defaults, and appearance. Each settings section has its own Save button—changes are only saved when you explicitly click the Save button for that section.

**Note:** Settings are stored locally on your device. If you use multiple devices or browsers, you'll need to configure settings on each separately.

## Location Settings

Configure your country and regional information:

### Country Selection

1. Go to the **Location** section
2. Select your country from the dropdown (searchable)
3. Country code is automatically set based on your selection
4. Click **Save** to apply your location settings

The country code is displayed as read-only and automatically updates when you change the country.

## Localization Settings

Configure language and timezone preferences:

### Language Preference

Select the language for the user interface:

**Available Languages:**
- English
- French (Français)
- Spanish (Español)
- Swahili (Kiswahili)

**How to Change:**
1. Go to the **Localization** section
2. Select your desired language from the dropdown
3. Click **Save** to apply changes
4. Interface language updates on your next page refresh

### Timezone

1. Select your local timezone from the dropdown (searchable)
2. Timezone includes UTC offset (e.g., "Africa/Nairobi (+03:00)")
3. Used for displaying timestamps throughout the system
4. Click **Save** to apply changes

## Date & Number Format Settings

Configure how dates and numbers display:

### Date Format

Choose from these format options:
- YYYY-MM-DD (ISO standard)
- MM/DD/YYYY (United States)
- DD/MM/YYYY (Europe/UK)
- DD-MM-YYYY
- MM-DD-YYYY
- YYYY/MM/DD

A live preview shows how today's date will appear in your selected format. Click **Save** to apply changes.

### Currency & Number Formatting

**Currency:**
- Select from all available currency codes (searchable by code or country)

**Number Format:**
- 1,234.56 (comma thousands, period decimal)
- 1 234,56 (space thousands, comma decimal)
- 1.234,56 (period thousands, comma decimal)
- 1'234.56 (apostrophe thousands, period decimal)

A live preview shows how the number 1,234.56 appears in your selected format. Click **Save** to apply changes.

## Communication Preferences

Configure defaults for sending communications throughout the system:

### Character Set (SMS Encoding)

Select the text encoding for SMS messages:

1. Go to the **Character Sets** section
2. Choose from available character set options (e.g., GSM-7, UTF-8, ASCII, UCS-2)
3. Descriptions are provided for each encoding option
4. Click **Save** to apply your selection

The character set affects how SMS messages are encoded and their message length limits.

### Default Sender ID

Configure the default SMS sender ID for outgoing communications:

1. Go to the **Default Sender ID** section
2. Select from available sender IDs (managed by administrators)
3. Only active sender IDs appear in the dropdown
4. Click **Save** to apply changes

Sender ID options are configured by system administrators and reflect the approved IDs for your account.

### Default Communication Channel & Route

Set the default communication method and its corresponding route:

1. Go to the **Default Communication Channel & Route** section
2. Select your default channel from the dropdown
3. Based on your channel selection, a route dropdown appears:
   - **SMS** → Select SMS Route
   - **Email** → Select Email Route
   - **USSD** → Select USSD Route
   - **WhatsApp** → Select WhatsApp Route
   - **Push Notification** → Select Push Notification Route
4. Routes are configured by administrators and reflect active options
5. Click **Save** to apply changes

Only active routes for your selected channel are available. If a channel has no routes, the route selection is hidden.

## Display Theme Settings

Choose how the user interface appears:

### Theme Selection

**Available Options:**

- **Light Mode** - Bright interface with dark text (default)
- **Dark Mode** - Dark interface with light text

**How to Change:**

1. Go to the **Display Theme** section
2. Select your preferred theme from the dropdown
3. Click **Save** to apply changes
4. Interface appearance updates immediately

## Notification Settings

To configure notification preferences, subscriptions, channels, and Do Not Disturb (DND) hours:

1. Click the **Go to Notification Settings** button in the Notification Settings card
2. Or navigate directly to [Notification Settings](/documentation/user-settings/notification-settings)

See [Notification Settings](/documentation/user-settings/notification-settings) for complete documentation on managing notification preferences.

## Saving Your Settings

Each settings section has its own **Save** button:

1. Make your changes in any section
2. Click the **Save** button for that section
3. You'll see a confirmation message when changes are saved successfully
4. Settings are stored locally on your device and persist across browser sessions
