# Notifications

## Overview

The Notifications page allows you to view, filter, and manage all notifications you've received. You can search for specific notifications, filter by type or priority, and bulk manage multiple notifications at once.

**Note:** For notification preferences and settings (like Do Not Disturb, notification types, channels, and sounds), click the **Notification Settings** button on this page or go to [Notification Settings](/documentation/user-settings/notification-settings).

## Accessing Notifications

### From the Header Notification Dropdown

![Notification Dropdown](/img/v1.1/usersettings/notificationsdropdown.png)

**Step 1: Open Notification Center**
- Click the **bell icon** in the top-right header
- A dropdown appears showing your most recent notifications
- **Badge count** on the bell shows number of unread notifications
- Click the settings icon to take you to the [**Notification Settings**](/documentation/user-settings/notification-settings) page

**Notification Dropdown Details:**
- Shows your **5 most recent notifications** in the dropdown
- Each notification displays:
  - **Title** - Notification subject
  - **Type** - Category icon/label (campaigns, offers, segments, etc.)
  - **Timestamp** - When you received it
  - **Read status** - Unread notifications appear highlighted
- Click any notification to open it and mark as read
- Unread badge count updates automatically as you read notifications

**Step 2: View All Notifications**
- Click **"View all notifications"** button at the bottom of the dropdown
- Takes you to the full Notifications page with all your notifications, filters, and bulk actions
- This is useful when you have more than 5 recent notifications and need to find a specific one

## Notification Center

![Notifications Page](/img/v1.1/usersettings/notificationspage.png)

### Notification List

The main Notifications page displays:

**Header Information:**
- **Total Notifications** - Total number of notifications in system
- **Unread Count** - Number of unread notifications
- **Mark All As Read** button
- **Delete All** button

**Notification Entries:**
Each notification in the list shows:
- **Title** - The notification subject
- **Message** - Notification content
- **Type** - Category (campaign, offer, segment, product, etc.)
- **Priority** - Urgency level (low, medium, high, urgent)
- **Timestamp** - When you received it
- **Read Status** - Whether you've seen it

## Filtering Notifications

### Available Filters

You can filter notifications by multiple criteria:

**Search:**
- Type keywords to search notification titles and messages
- Search is real-time as you type

**Type Filter:**
- All Types (default)
- Campaigns
- Offers
- Segments
- Products
- Jobs
- Users
- System

**Priority Filter:**
- All Priorities (default)
- Low
- Medium
- High
- Urgent

**Read Status Filter:**
- All (default)
- Unread only
- Read only

### Clear Filters

Click "Clear Filters" to reset all filters and see all notifications again.

## Managing Notifications

### Mark as Read

**Single Notification:**
1. Click on a notification to open it
2. It automatically marks as read
3. Unread badge count decreases

**Bulk Operations:**
1. Click "Mark All As Read" button
2. All unread notifications marked as read
3. Unread badge clears

### Delete Notifications

**Single Notification:**
1. Find the notification in the list
2. Click the delete icon (trash can)
3. Notification is removed

**Bulk Delete:**
1. Click "Delete All" button
2. Confirm deletion
3. All notifications removed from the list

### Select Notifications

**Single Selection:**
- Click checkbox next to a notification
- Selected notifications highlighted

**Select All:**
- Click "Select All" button in bulk actions bar
- Selects all visible (filtered) notifications
- Deselect All to uncheck all

## Bulk Actions

When you have notifications selected, a bulk actions bar appears:

**Available Actions:**
- **Select All** - Select all visible notifications
- **Selected Count** - Shows how many are selected (e.g., "5 selected")
- **Mark As Read** - Mark selected as read
- **Delete** - Delete selected notifications

## Managing Your Notification Preferences

To control which types of notifications you receive and through which channels:

1. Click the **Notification Settings** button (top right of this page)
2. Or navigate to **Notification Settings** from your user settings
3. Configure your preferences:
   - **Enable/Disable Notification Types** - Check or uncheck each notification type to control what you're notified about
   - **Select Preferred Channels** - Choose which communication channels (SMS, Email, Push, etc.) you want to use for notifications
   - **Set Do Not Disturb Hours** - Configure quiet hours when you don't want notification alerts

See [Notification Settings](/documentation/user-settings/notification-settings) for detailed information.
