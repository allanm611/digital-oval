# Segment Analytics

## Overview

Segment Analytics provides visual insights into segment health, distribution, and usage across the platform.

![Segment Reports Overview](/img/v1.1/reports/segmentreportsimage1.png)

![Segment Reports Visualizations](/img/v1.1/reports/segmentreportsimage2.png)

## Summary Cards

## Visualizations

- **Segment Type Distribution**: Pie chart showing the breakdown of segment types
- **Category Distribution**: Bar chart of segment categories
- **Creation Trend**: Line chart of segment creation over the last 30 days
- **Top 10 Largest Segments**: Bar chart of the largest segments by size
- **Top Segments by Campaign Usage**: Bar chart of segments most used in campaigns
- **Stale Segments Table**: Table listing segments not computed recently, with days since last computation

## Accessing Segment Analytics

1. Navigate to **Reports** in the main navigation
2. Select **Segment Analytics**
3. The analytics dashboard will load with all visualizations and summary cards

_Data is loaded from the backend. There is no data mode toggle in this section._
