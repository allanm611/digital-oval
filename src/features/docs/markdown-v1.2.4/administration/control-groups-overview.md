# Control Groups

## Overview

Control Groups are customer segments that do not receive a campaign message, used as a baseline to measure the true impact of your campaigns.

## What are Control Groups?

Control Groups allow you to:

- **Create Baseline Audiences** - Define customer groups that receive no message
- **Measure Campaign Impact** - Compare treatment group results against control group baseline
- **Track Metrics** - Monitor member count and generation schedules
- **Test Generation Methods** - Use random or stratified selection for member assignment

## Key Features

- **Multiple Customer Base Options**: Active Subscribers, All Customers, or Custom Conditions
- **Flexible Scheduling**: One-time, Daily, Weekly, or Monthly generation
- **Generation Methods**: Random or Stratified member selection
- **Member Management**: Add or remove members directly
- **Universal Control Groups**: Mark groups as universal for system-wide use
- **Status Tracking**: Active or Inactive states

## Getting Started

To manage universal control groups:

1. Navigate to **Configuration** → **Universal Control Groups**
2. View existing control groups and their status
3. Create new control groups using the create button
4. Manage members on the control group details page
5. Monitor control group statistics
