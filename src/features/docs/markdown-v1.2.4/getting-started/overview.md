# Getting Started

## Overview

Getting Started guides help you learn the fundamentals of the Sentra CVM platform. Whether you're new to the system or need a quick refresher, these guides explain core features and how to navigate the system.

## Platform Navigation

### Sidebar Structure

![Sidebar](/img/v1.2.4/sidebar.png)

The sidebar menu on the left is organized into major sections:

- **Authentication** - Login, registration, password reset
- **Campaign Management** - Campaigns, broadcasts, objectives, catalog
- **Offer Management** - Offers, catalog, and offer types
- **Product Management** - Products, catalog, and product types
- **Segment Management** - Segments, quicklists, catalog
- **Customer 360 Profile** - Customer data, identity, KPIs
- **Administration** - Infrastructure, jobs, communication channels, routes, sender IDs, control groups, notification types, timezones, gateway configurations, and execution monitoring
- **Configuration** - Campaign policies, departments, programs, DND management, VIP lists, seed lists, languages, and more
- **Reports** - Analytics and performance data

### Footer Information

![Footer](/img/v1.2.4/footer.png)

The footer displays three important settings:
- **Selected Country** - Active country setting
- **Selected Timezone** - Active timezone for all time-based operations
- **Selected Currency** - Currency used for financial displays

Update these settings in your profile to change how data is displayed across the platform.

## Essential Guides

**[Dashboard](/documentation/getting-started/dashboard)** - Learn about the main landing page you see after logging in. Understand the dashboard layout, key statistics, charts, recent items, and how to navigate to different modules from the dashboard.

**[Global Search](/documentation/getting-started/global-search)** - Master the platform-wide search feature that helps you quickly find campaigns, offers, products, segments, users, and configurations from anywhere in the system. Discover how to use the search dropdown, access the results page, and filter by type.


## Quick Tips

**New to Sentra CVM?**

1. Familiarize yourself with the [Dashboard](/documentation/getting-started/dashboard) layout
2. Learn to use [Global Search](/documentation/getting-started/global-search) for quick item lookup
3. Use the sidebar navigation to explore different modules
4. Refer to module-specific documentation as you work with campaigns, offers, products, and segments

## Next Steps

Once you're comfortable with the basics:

- Explore [Campaign Management](/documentation/campaigns/overview) to create and manage campaigns
- Dive into [Customer 360](/documentation/customer-360/overview) to understand your customer data
- Check out [Reports](/documentation/reports/overview) to track performance
- Build [Segments](/documentation/segments/overview) to target specific customer groups
