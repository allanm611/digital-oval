# Offer Types

## Overview

Offer Types are categories used to classify and organize different kinds of promotional offers in your system. Each offer must be assigned to a type, which helps you organize offers, filter by category, track performance metrics by type, and support type-specific handling in campaigns and analytics. Offer types provide structure to your promotional catalog and enable consistent management across your organization.

## Purpose & Benefits

### Why Use Offer Types?

**Organization & Structure**
- Categorize offers by their nature (Data, Voice, SMS, Vouchers, etc.)
- Create a taxonomy of your promotional offerings
- Organize offers in the offer catalog
- Support easy discovery and filtering

**Analytics & Reporting**
- Track performance metrics by offer type
- Compare effectiveness across types
- Identify which types drive revenue
- Measure ROI by offer type

**Campaign Management**
- Associate campaigns with specific offer types
- Filter offers by type when building campaigns
- Create type-specific campaign strategies
- Monitor type-specific campaign performance

**Consistency & Control**
- Standardize offer naming and classification
- Ensure all offers are properly categorized
- Support business processes
- Enable type-specific validation rules

### Key Benefits

- **Clarity:** Clear categorization of all promotional offerings
- **Filtering:** Quick access to offers by type
- **Analytics:** Type-specific performance tracking
- **Strategy:** Type-based campaign and targeting decisions
- **Consistency:** Standardized offer organization

## Offer Types

Offer types represent the fundamental nature of your promotional offerings. The system includes 10 primary offer types:

### Data Offers

**Description:** Data bundle and data package offerings

**Use For:**
- Monthly data packages
- Data bundles for mobile devices
- High-speed data add-ons
- Roaming data packages
- International data plans

**Characteristics:**
- Measured in GB/MB
- Time-limited or unlimited
- Device or network specific
- Speed tier variations

**Examples:**
- "5GB Monthly Data Plan"
- "Unlimited Data Weekend Package"
- "International Roaming 1GB"

---

### Voice Offers

**Description:** Voice call and voice package offerings

**Use For:**
- Voice call packages
- Minute bundles
- Call plan offerings
- Unlimited calling plans
- International calling packages

**Characteristics:**
- Measured in minutes
- Geographic scope (local, national, international)
- Time-bound validity
- Destination-specific

**Examples:**
- "500 Local Minutes Monthly"
- "Unlimited Voice Calls National"
- "International Calling Package 100 Minutes"

---

### SMS Offers

**Description:** SMS text message offerings

**Use For:**
- SMS bundles
- Message packages
- SMS plans
- Unlimited SMS packages
- International SMS packages

**Characteristics:**
- Measured in SMS count
- Recipient scope (local, national, international)
- Time-limited
- Network-dependent pricing

**Examples:**
- "100 SMS Monthly"
- "Unlimited SMS National"
- "International SMS Add-on 50 Messages"

---

### Combo Offers

**Description:** Combined bundled offerings (Data + Voice + SMS)

**Use For:**

**Characteristics:**
- Multiple service components
- Package pricing
- Bundled value proposition
- Complex eligibility

**Examples:**
- "5GB Data + 500 Minutes + 100 SMS"

- "Family Combo 3GB + 1000 Minutes Each"

---

## Offer Type Characteristics

### Common Properties

All offer types share these properties:

**Type ID**
- System-generated unique identifier
- Used for filtering and reporting
- Immutable once created

**Type Name**
- Display name of the offer type
- 1-100 characters
- Human-readable identifier

**Description**
- Optional explanation of the type
- Up to 500 characters
- Helps users understand the type's purpose

**Status**
- Active or Inactive
- Determines if new offers can use this type
- Archived types show in historical data

**Creation Metadata**
- Created date and time
- Last updated date and time
- Used for audit trails

## Using Offer Types

### Creating Offers with Types

When creating a new offer, offer type selection is **required**:

**Step 1: Select Offer Type**
- Navigate to Create Offer
- Choose offer type from dropdown
- Each offer type selection changes available fields

**Step 2: Configure Offer Details**
- Fill in offer-specific details
- Offer type determines required fields
- Validation rules apply based on type

**Step 3: Complete Offer**
- Finish offer creation
- Offer is now classified by type
- Type is immutable after creation

### Filtering Offers by Type

**In Offer Management:**
- Filter offer list by type
- View all offers of specific type
- Compare metrics across types

**In Campaign Creation:**
- Filter available offers by type
- Select offers of desired type(s)
- Type-specific campaign strategies

**In Analytics:**
- View performance by offer type
- Compare type effectiveness
- Identify top-performing types

## Best Practices

### Offer Type Strategy

**Clear Definition**
- Define what each type represents
- Document type-specific rules
- Ensure team understanding
- Keep definitions consistent

**Consistent Application**
- Apply types consistently across offers
- Use same type for similar offers
- Don't mix purposes within type
- Document exceptions

**Meaningful Organization**
- Use types that reflect your business
- Don't create redundant types
- Keep number of types manageable (10-20)
- Review and consolidate periodically

### Offer Type Selection

**Match Offer Nature to Type**
- "20% Off" → Discount Offer
- "1GB + 200 Minutes" → Combo Offer
- "500 Bonus Points" → Loyalty Offer
- "Free Premium Feature" → Bonus Offer

**Avoid Misclassification**
- Don't force offers into wrong types
- Use "Other" sparingly
- Consider creating new type if recurring need
- Document why type was chosen

### Analytics & Reporting

**Track by Type**
- Monitor performance metrics per type
- Compare type effectiveness
- Identify top-performing types
- Use for budget allocation

**Type Performance**
- Revenue by type
- Redemption rates by type
- Customer response by type
- ROI by type

## Common Use Cases

### Use Case 1: Tiered Service Offerings

**Scenario:** Telecom company with tiered data packages

**Offer Type Strategy:**
- Data Offers for tiered packages (500MB, 2GB, 5GB)
- Combo Offers for bundled services
- Loyalty Offers for retention

**Campaign Approach:**
- Create tier-specific campaigns
- Target by offer type and customer segment
- Track type-specific performance
- Optimize tier based on metrics

**Benefit:** Consistent packaging and clear customer options

---

### Use Case 2: Seasonal Promotions

**Scenario:** Retail company with seasonal campaigns

**Offer Type Strategy:**
- Discount Offers for sales (Black Friday, Summer)
- Bundle Offers for gift seasons
- Loyalty Offers for year-round retention

**Campaign Approach:**
- Season-specific campaigns by type
- Different strategies per type
- Type-specific messaging
- Measure type performance by season

**Benefit:** Clear seasonal positioning and measured results

---

### Use Case 3: Retention vs Acquisition

**Scenario:** Balancing new customer acquisition and existing customer retention

**Offer Type Strategy:**
- Bonus Offers for new customers (attract)
- Loyalty Offers for existing customers (retain)
- Discount Offers for win-back campaigns

**Campaign Approach:**
- Acquisition campaigns feature Bonus offers
- Retention campaigns feature Loyalty offers
- Win-back campaigns feature Discount/Loyalty combo
- Measure acquisition vs retention ROI

**Benefit:** Clear targeting strategy with measurable results
