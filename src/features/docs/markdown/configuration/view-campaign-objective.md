# View Campaign Objective Details

## Overview

View detailed information about a Campaign Objective. This page displays the objective's name, description, and how it's used across campaigns.

## How to View Objective Details

### From the List View
1. Navigate to **Configuration → Campaign Objectives**
2. Click on any objective name in the list
3. The details page opens

### From Search Results
1. Use the search field to find an objective
2. Click on the matching objective
3. Details page loads

## Objective Details Page

### Basic Information

**Objective Name**
- The unique identifier for the objective
- Used when creating campaigns
- Examples: "New Customer Acquisition", "Churn Prevention"

**Description**
- Detailed explanation of the objective's purpose
- Helps team understand the business goal
- Guides campaign strategy

**Created Date**
- When the objective was created
- Helps track objective lifecycle

**Last Updated**
- Most recent modification date
- Shows if objective has been updated

### Related Information

**Campaigns Using Objective**
- Number of active campaigns
- List of campaigns
- Campaign status for each

**Performance Metrics**
- Campaigns count by this objective
- Total messages sent via objective
- Engagement rates
- Conversion data

## Available Actions

### Edit Objective
- Click **Edit** button to modify details
- Update name or description
- See [Edit Campaign Objective](/documentation/edit-campaign-objective)

### Delete Objective
- Click **Delete** button to remove
- Confirmation dialog appears
- Cannot delete if campaigns use it

### Back to List
- Returns to Campaign Objectives list

## Using Objectives in Campaigns

### Selecting Objective When Creating Campaign
1. Navigate to Campaign creation
2. Select an objective from dropdown
3. Objective guides campaign configuration
4. Helps categorize campaign

### Objective Context
Objectives provide:
- **Strategic Clarity** - Clear campaign purpose
- **Team Alignment** - Everyone understands goal
- **Measurement** - Know what to measure
- **Organization** - Categorize campaigns

## Reporting by Objective

### Performance Analysis
- Campaign success by objective
- Cumulative performance metrics
- Objective effectiveness
- Resource allocation

### Campaign Grouping
- View all campaigns for objective
- Compare performance across campaigns
- Identify patterns by objective
- Optimize by objective

## Related Objectives

Sometimes objectives are related:
- **New Acquisition → Retention** - Acquired customers need retention
- **Retention → Upsell** - Retained customers are candidates for upsell
- **Churn Prevention → Reactivation** - Failed prevention may need reactivation

Consider relationships when planning campaigns.

## Best Practices

### Understanding Objectives
- Read description carefully
- Understand the business goal
- Know what success looks like
- Review campaigns using objective

### Using in Campaigns
- Select objective that matches campaign goal
- Don't force objective fit
- Use objective to guide messaging
- Track performance against objective
