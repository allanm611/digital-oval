# Product Categories

## Overview

Product Categories organize products into groupings for easier management and organization. Categories help you group related products together and manage them as a collection.

## Summary Statistics

The Product Categories page displays key metrics at the top in five stat cards:

- **Total Categories** - Total number of product categories in your system
- **Active** - Number of currently active categories
- **Inactive** - Number of inactive categories
- **With Products** - Number of categories that contain products
- **Unused** - Number of categories that have no products assigned

## Category Cards

Categories are displayed as cards in a grid or list view with the following information:

**Grid View:**
- Category name
- Description (if provided)
- Number of products in the category (with active count)
- Performance metrics (Revenue and Conversion Rate, if applicable)
- Action buttons (View Products, Toggle Active, Edit, Delete)

**List View:**
- Category name and description
- Number of products with active count
- Performance metrics in a side-by-side layout
- View Products link
- Action buttons (Toggle Active, Edit, Delete)

## Category Actions

### Create Category

Click the **Create** button to open the create category modal:

- **Category Name*** (required) - Descriptive name for your category
- **Description** (optional) - Additional details about the category

### Edit Category

Click the **Edit** button (pencil icon) on any category card to modify:

- Category name
- Category description

### Toggle Active Status

Click the power icon on any category card to enable or disable it:

- **Power On icon (green)** - Category is inactive, click to activate
- **Power Off icon (orange)** - Category is active, click to deactivate

### Delete Category

Click the **Delete** button (trash icon) to permanently remove a category. You will be asked to confirm the deletion.

## View Products in Category

Click the **View Products** button on any category card to open the View Products modal. This modal displays:

- All products assigned to this category
- Product name and description
- Product status badge (Active, Inactive)
- Option to remove products from the category individually

## Add Products to Category

Click the **Add Products** action button within the View Products modal to open the Add Products to Category modal.

**Search and Filters:**
- **Search** - Find products by name or description
- **Status Filter** - Filter by product status (All Statuses, Active, Inactive)

**Product Selection:**
- Click the checkbox next to any product to select it
- Click **Select All** to select all available products at once
- The selection counter shows how many products you've selected

**Assignment:**
- Click the **Assign Selected** button to add the selected products to this category
- Already assigned products appear dimmed and cannot be selected again
- A success message appears when products are assigned

## Search and Filters

### Search

Use the **Search** field to find categories by:
- Category name
- Category description

### Advanced Filters

Click the **Filters** button to access filtering options:

- **Unused Categories** - Show only categories with no products
- **Popular Categories** - Show only the most frequently used categories
- **Active Categories** - Show only active categories
- **Inactive Categories** - Show only inactive categories

### View Mode

Toggle between:
- **Grid View** - Cards displayed in a grid layout
- **List View** - Categories displayed in a list with full details

## Managing Category Contents

Each category card shows the total number of products, including the count of active products. Click **View Products** to:

- See all products in that category
- Remove products individually (if they are not the primary category)
- Add more products using the Add Products modal
