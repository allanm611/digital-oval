# Programs Overview

Programs represent structured initiatives or customer engagement frameworks within your organization. They provide a way to organize, categorize, and manage different types of customer campaigns, loyalty initiatives, or marketing programs.

## What are Programs?

Programs are:
- **Organizational Structures** - Represent major customer engagement initiatives
- **Campaign Groupings** - Organize campaigns under strategic programs
- **Loyalty Frameworks** - Create loyalty or rewards programs
- **Initiative Containers** - Group related business initiatives
- **Performance Tracking** - Monitor program-level metrics and results

## Purpose & Benefits

### Why Use Programs?

**Strategic Organization**
- Group related campaigns under strategic initiatives
- Align campaigns with business programs
- Organize by loyalty tiers or customer segments
- Create clear program hierarchies

**Program Management**
- Track all campaigns within a program
- Monitor program-level performance
- Allocate budgets to programs
- Manage program-specific workflows

**Unified Tracking**
- View all program metrics at a glance
- Track ROI by program
- Monitor customer engagement by program
- Compare program performance

**Flexibility**
- Create custom programs for your business model
- Organize programs by type or department
- Manage program lifecycle
- Scale programs as needed

### Key Benefits

- **Organization:** Clear categorization of all your initiatives
- **Strategy:** Align campaigns with business programs
- **Tracking:** Monitor performance by program
- **Reporting:** Comprehensive program-level analytics
- **Management:** Centralized program administration
- **Flexibility:** Fully customizable program definitions

## Managing Programs

### Viewing Programs List

Navigate to **Configuration → Programs** to see all configured programs.

![Programs List](/img/configuration/programslist.png)

### Create Program

Click the **Create** button to add a new program.

![Create Program](/img/configuration/createprogram.png)

**Program Configuration:**
1. **Program Name** (Required)
   - Descriptive name for your program
   - Examples: "VIP Loyalty Program", "New Customer Acquisition", "Reactivation Campaign"
   - Max 100 characters

2. **Description** (Optional)
   - Explain the program's purpose and scope
   - Business objectives and target outcomes
   - Max 500 characters

3. **Program Type** (Optional)
   - Categorize the program (Loyalty, Acquisition, Retention, etc.)
   - Helps organize and identify similar programs
   - Enables filtering and reporting

4. **Status** (Optional)
   - Set program as Active or Inactive
   - Inactive programs are archived but retained
   - Can be reactivated later

### Edit Program

Click the **Edit** button on any program to update:
- Program name
- Description
- Program type
- Status

### Delete Program

Click the **Delete** button to remove a program:
- Program is permanently removed
- Campaigns assigned to the program are not deleted
- Verify no active campaigns use this program before deleting

## Using Programs in Campaigns

### Assigning Campaigns to Programs

When creating or editing a campaign:

1. Go to Campaign creation/editing workflow
2. Select **Program** from available programs
3. Choose the program that this campaign belongs to
4. Continue with campaign configuration

### Organizing Campaign Portfolio

**By Program:**
- View all campaigns across programs
- Filter by program name

- Track program-level performance

## Best Practices

### Program Design

1. **Clear Purpose** - Define what each program is for
2. **Meaningful Names** - Use names that clearly describe the program
3. **Documented Goals** - Document program objectives
4. **Consistent Structure** - Use consistent naming and organization
5. **Regular Review** - Periodically review program relevance

### Campaign Organization

1. **Intentional Assignment** - Assign campaigns to appropriate programs
2. **Avoid Overlap** - Don't create overlapping programs
3. **Single Program** - Assign each campaign to one program
4. **Lifecycle Tracking** - Track campaigns from launch to completion
5. **Archive Completed** - Archive programs with no active campaigns

### Maintenance

1. **Regular Updates** - Keep program descriptions current
2. **Remove Unused** - Delete obsolete programs
3. **Monitor Performance** - Review program metrics regularly
4. **Align with Strategy** - Ensure programs align with business goals
5. **Team Communication** - Keep team informed of program changes

## Troubleshooting

### Cannot Create Program

**Issue:** "Program creation failed" error

**Solutions:**
- Verify program name is not empty
- Check name doesn't exceed 100 characters
- Verify name is unique (no duplicates)
- Ensure you have permission to create programs

### Cannot Delete Program

**Issue:** "Cannot delete program - campaigns exist" error

**Solutions:**
- View all campaigns in the program
- Delete or reassign campaigns to different program
- Then retry program deletion
- Alternatively, deactivate program instead of deleting

### Missing Programs

**Issue:** Expected program doesn't appear in list

**Solutions:**
- Check if program is inactive (filter to show inactive)
- Verify program name spelling
- Search by program description
- Check program creation was saved
