# Edit Campaign Objective

## Overview

Modify an existing Campaign Objective to update its name, description, or other details. Changes may affect how campaigns using this objective are understood.

## How to Edit an Objective

### Step 1: Open the Edit Form

#### From the List View
1. Navigate to **Configuration → Campaign Objectives**
2. Find the objective to edit
3. Click the **Edit** button next to the objective
4. The edit modal opens with current settings pre-filled

#### From the Details View
1. Navigate to **Configuration → Campaign Objectives**
2. Click the objective name to view details
3. Click the **Edit** button
4. The edit modal opens

### Step 2: Update Objective Information

#### Objective Name
- **Field Type:** Text input (max 100 characters)
- **Current Value:** Shows existing name
- **To Update:**
  1. Click in the field
  2. Modify the name as needed
  3. Ensure new name is unique

#### Description
- **Field Type:** Text area (max 500 characters)
- **Current Value:** Shows existing description
- **To Update:**
  1. Update the text
  2. Clarify purpose or scope
  3. Can be left empty

### Step 3: Save Changes

1. Review all modifications
2. Click the **Save** or **Update** button
3. System validates:
   - Name is unique
   - Name is provided
   - Character limits respected
4. Upon success:
   - Confirmation message appears
   - Modal closes
   - Changes take effect

## Validation Rules

- **Name is required** - Cannot be empty
- **Name must be unique** - No duplicate names
- **Character limits:**
  - Name: Maximum 100 characters
  - Description: Maximum 500 characters

## Common Edit Scenarios

### Correcting a Typo
**Scenario:** Objective name has spelling error
- **Change:** Fix spelling in name
- **Effect:** Clearer objective name
- **Impact:** No impact on campaigns

### Clarifying Purpose
**Scenario:** Description needs better explanation
- **Change:** Update description
- **Effect:** Team better understands objective
- **Impact:** No impact on functionality

### Renaming Objective
**Scenario:** Business strategy changes naming
- **Change:** Update objective name
- **Effect:** Reflects current terminology
- **Impact:** Affects campaign organization

### Expanding Scope
**Scenario:** Objective now covers more scenarios
- **Change:** Update description to reflect broader scope
- **Effect:** Better captures objective
- **Impact:** May change campaign categorization

## Impact Analysis

### Before Making Changes

Consider impact on:

**Campaigns Using Objective**
- Which campaigns reference this objective
- How name change affects understanding
- Whether change affects strategy

**Team Understanding**
- Will rename/change confuse team?
- Do team members know this objective?
- Should you announce changes?

### Planning Changes

1. **Assess Current Usage**
   - Review campaigns using objective
   - Check team familiarity
   - Plan communication

2. **Make Changes**
   - Update objective details
   - Document reason for change
   - Notify stakeholders

3. **Verify Impact**
   - Check campaigns still aligned
   - Confirm team understanding
   - Monitor campaign creation

## Undo Changes

### Before Saving
- Click **Cancel** or close modal without saving
- All changes are discarded
- Original settings remain unchanged

### After Saving
- Changes are permanent immediately
- To revert:
  1. Edit the objective again
  2. Restore previous values
  3. Save changes
- Keep documentation of changes

## Error Handling

Common errors and solutions:

- **"Name is required"** - Ensure name field is not empty
- **"Name already exists"** - Choose a unique name
- **"Name exceeds 100 characters"** - Shorten the name
- **"Description exceeds 500 characters"** - Shorten description

## Best Practices

### Documentation
- Document the reason for changes
- Keep version history
- Note impact on campaigns
- Communicate to team

### Testing
- Verify changes make sense
- Check campaign alignment
- Confirm team understanding

### Timing
- Make changes when convenient
- Avoid changing during campaign launches
- Notify team of significant changes
