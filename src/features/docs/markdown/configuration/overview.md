# Configuration

## Overview

Configuration settings control platform behavior, business rules, and system-wide parameters. Define departments, communication channels, campaign types, catalogs, and other organizational settings that shape how campaigns and offers work across your organization.


## What You Can Configure

### Campaign Configuration

#### [Campaign Types](/documentation/configuration/campaign-types)

Define the types of campaigns available for your organization. Configure which campaign structures (Multiple Target Group, A/B Testing, Champion Challenger, etc.) your team can use.

#### [Campaign Objectives](/documentation/configuration/campaign-objectives)

Set up campaign business objectives and purposes. Define the strategic goals campaigns can target (New Customer Acquisition, Retention, Churn Prevention, etc.).

#### [Campaign Catalog](/documentation/configuration/campaign-catalog)

Organize and manage campaign categories. Create catalogs to group related campaigns for better organization and reporting.

### Organizational Structure

#### [Departments](/documentation/configuration/departments)

Set up organizational departments. Create and manage departments to organize teams and campaigns by business unit.

#### [Programs](/documentation/configuration/programs)

Create campaign programs that group related campaigns together. Organize campaigns by program for better tracking and management.

### Communication & Channels

#### [Communication Channels](/documentation/configuration/communication-channels)

Configure available communication channels. Set up SMS, Email, WhatsApp, Push, and other channels for customer outreach.

#### [DND Management](/documentation/configuration/dnd-management)

Set up Do Not Disturb rules and quiet hours. Define when customers should not receive communications.

#### [Sender IDs](/documentation/configuration/sender-ids)

Configure sender identities for SMS and other channels. Set up sender names and IDs for outbound communications.

### Offer & Product Configuration

#### [Offer Types](/documentation/configuration/offer-types)

Define offer categories and types. Set up offer classifications for your business.

#### [Offer Catalog](/documentation/configuration/offer-catalog)

Organize offers into catalogs. Create offer categories for better organization.

#### [Offer Tracking Sources](/documentation/configuration/offer-tracking-sources)

Configure tracking and attribution sources for offers. Define how offer performance is tracked.

#### [Product Catalog](/documentation/configuration/product-catalog)

Organize products into categories. Create product catalogs for grouping and organization.

### Segment Configuration

#### [Segment Catalog](/documentation/configuration/segment-catalog)

Organize segments into catalogs. Create segment categories for better organization.


## Quick Start

**Getting Started with Configuration:**

1. Set up your [Departments](/documentation/configuration/departments) to organize your team
2. Configure [Communication Channels](/documentation/configuration/communication-channels) for outreach
3. Define [Campaign Objectives](/documentation/configuration/campaign-objectives) for your organization
4. Create [Catalogs](/documentation/configuration/campaign-catalog) to organize campaigns and offers
5. Review configuration coverage and validate setup before launching campaigns
