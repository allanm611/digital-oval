# Create Segment

## Overview

Create custom customer segments based on various criteria to build targeted audiences for campaigns.

**[Insert screenshot of segment builder modal]**


## Form Fields

### Basic Information

**Segment Name*** (required)
- Descriptive name for your segment

**Description** (optional)
- Additional details about the segment's purpose

**Category** (optional)
- Assign the segment to a catalog category for organization


## Segment Conditions

### Building Conditions

Define the criteria that determines which customers belong to this segment. The Segment Conditions Builder supports multiple condition types:

**360 Profile Conditions**
- Rules based on customer profile attributes
- Demographic, behavioral, and transactional data

**Segment Conditions**
- Reference other segments as part of your criteria

**Quick List Conditions**
- Include customers from predefined quick lists

**System Event Conditions**
- Conditions based on system events

**KPI Conditions**
- Rules based on Key Performance Indicators

### Condition Logic

- **AND** - All conditions must be true
- **OR** - Any condition can be true
- Combine multiple conditions to create complex rules


## Tags

Add tags to organize and label your segment:
- Press Enter to add a new tag
- Tags can be used for filtering and organization
- Remove tags by clicking the delete button


## Preview & Confirmation

### Preview Segment Size

Before creating your segment:
- Click **Preview** to see the estimated audience size
- The preview shows how many customers match your criteria
- Use this to verify your segment captures the right audience

### Confirm & Create

When you're ready:
- Click **Create Segment** to save your segment
- The segment will be available immediately for use in campaigns


## Next Steps

After creating a segment, you can:
- View segment details on the [Segment List](/documentation/segments/segments-list)
- Edit the segment using [Edit Segment](/documentation/segments/segment-edit)
- View detailed information on the [Segment Details](/documentation/segments/view-segment-details) page
- Compute segment membership to get accurate audience size
