# Segment Reports

## Overview

Segment Reports provide analytics on segment performance, engagement, and impact across campaigns.


## Key Metrics

### Segment Size Metrics
- **Total Customers** - Segment size
- **Active Customers** - Customers actively engaged
- **Inactive Customers** - Dormant accounts
- **Growth Rate** - Segment growth over time

### Performance Metrics
- **Engagement Rate** - % engaged in campaigns
- **Conversion Rate** - % converting
- **Revenue** - Revenue from segment
- **Customer Lifetime Value** - Long-term value


### Campaign Performance
- **Campaigns Run** - Number of campaigns
- **Campaign Response** - How segment responds
- **Best Performing Campaign** - Most successful
- **Average Performance** - Typical results
