# View Manual Reward

## Overview

View detailed information about a manual reward from the rewards list, including reward details, recipient information, and application status.

## How to Access

**From Rewards List**
1. Navigate to **Manual Actions → Manual Rewards**
2. Click the reward name or **View** button
3. Reward details display

**From Search Results**
1. Search for a reward
2. Click on matching result
3. Reward information shows

## Reward Information Displayed

### Basic Details
- **Reward Name:** Name/label of the reward
- **Reward Type:** Bundle, Points, Discount, or Cashback
- **Reward Value:** Amount or quantity awarded
- **Description:** Any additional details about the reward

### Recipient Information
- **Total Recipients:** How many customers targeted
- **Applied Count:** Number successfully awarded
- **Failed Count:** Number of failures
- **Success Rate:** Percentage of successful applications

### Status & Timeline
- **Current Status:** Applied, Pending, Scheduled, or Failed
- **Created At:** Date and time created
- **Created By:** User who created the reward
- **Scheduled Time:** When reward will be applied (if scheduled)

### Application Details

If reward has been applied:
- **Application Date/Time:** When it was applied
- **Execution Time:** How long application took
- **Final Count:** Total successfully awarded

### Failed Recipients (if applicable)

If there were failures:
- List of failed customer records
- Reasons for each failure
- Error codes or messages

## Available Actions

From the reward view, you can:

- **Edit** - Modify scheduled reward settings
- **Retry** - Retry failed applications
- **Delete** - Permanently remove the reward
- **Download Report** - Export reward details and metrics

## Best Practices

### Review Information
- Check success rate of reward application
- Review failed recipients if any
- Verify reward was applied to correct audience

### Monitor Impact
- Track how many customers received the reward
- Monitor application success rate
- Review failure patterns if applicable

### Documentation
- Download reports for records
- Archive important reward applications
- Document lessons learned from failed applications

## Status Meanings

**Applied**
- Reward successfully awarded to customers
- Application is complete
- Customers can now use reward

**Scheduled**
- Reward is queued for future application
- Waiting for scheduled time
- Can still be edited or cancelled

**Pending**
- Reward application is currently in progress
- Customers being awarded the reward
- Cannot be modified

**Failed**
- Reward application encountered errors
- Some or all customers didn't receive reward
- May be eligible for retry
