# Edit Manual Communication

## Overview

Editing a manual communication follows the **same 3-step process as creating** a new communication. The only difference is that all fields are pre-filled with your current settings, so you only need to modify what you want to change.

For the complete step-by-step guide, see [Create Manual Communication](/documentation/manual-actions/create-manual-communication).

## When You Can Edit

**You can edit if:**
- Status is **Scheduled** (awaiting execution)
- Execution time has not been reached yet
- No messages have been sent yet

**You cannot edit if:**
- Status is **Completed** (already sent)
- Status is **Pending** (currently sending)
- Status is **Failed** (already attempted)
- Execution time has passed

## How to Access Edit

**From Communications List**
1. Navigate to **Manual Actions → Manual Communications**
2. Find the scheduled communication
3. Click **Edit** button

**From Details Page**
1. View communication details
2. Click **Edit Communication** button

## Editing Workflow

The editing form shows all three steps with your current settings pre-filled:

1. **Step 1: Audience** - Change audience source, quicklist, or upload new file
2. **Step 2: Communication & Test** - Modify message, channel, variables, or policies
3. **Step 3: Schedule** - Change execution date/time

Make your changes, then click **Save** to update the communication. Changes take effect at the new execution time.

## What Can Be Changed

- **Audience:** Change quicklist, upload new file, modify customer list
- **Message:** Edit content, change channel (Email/SMS/WhatsApp/Push)
- **Variables:** Add or remove personalization variables
- **Policy:** Update communication policies
- **Execution Time:** Reschedule to earlier or later date/time
- **SMS Route:** Change SMS provider (if applicable)

## Best Practices

- Make one major change at a time
- Use the preview feature to verify changes
- Save promptly once satisfied with changes
- Confirm the new execution time before leaving edit mode

For detailed instructions on each field and step, refer to [Create Manual Communication](/documentation/manual-actions/create-manual-communication).
