# Edit Manual Reward

## Overview

Editing a manual reward follows the **same 4-step process as creating** a new reward. The only difference is that all fields are pre-filled with your current settings, so you only need to modify what you want to change.

For the complete step-by-step guide, see [Create Manual Reward](/documentation/manual-actions/create-manual-reward).

## When You Can Edit

**You can edit if:**
- Status is **Scheduled** (awaiting application)
- Application time has not been reached yet
- Reward has not been applied yet

**You cannot edit if:**
- Status is **Applied** (already awarded)
- Status is **Pending** (currently applying)
- Status is **Failed** (already attempted)
- Application time has passed

## How to Access Edit

**From Rewards List**
1. Navigate to **Manual Actions → Manual Rewards**
2. Find the scheduled reward
3. Click **Edit** button

## Editing Workflow

The editing form shows all four steps with your current settings pre-filled:

1. **Step 1: Audience** - Change customer list or upload new file
2. **Step 2: Reward** - Modify reward type, value, or communication policy
3. **Step 3: Preview** - Review changes before applying
4. **Step 4: Apply** - Change application date/time

Make your changes, then click **Save** to update the reward. Changes take effect at the new application time.

## What Can Be Changed

- **Audience:** Change quicklist, upload new file, modify customer list
- **Reward Type:** Change from bundle to points, discount, or cashback
- **Reward Value:** Update amount or quantity
- **Communication Policy:** Update notification settings
- **Application Time:** Reschedule to earlier or later date/time

## Best Practices

- Make one major change at a time
- Use the preview step to verify changes
- Save promptly once satisfied with changes
- Confirm the new application time before leaving edit mode

For detailed instructions on each field and step, refer to [Create Manual Reward](/documentation/manual-actions/create-manual-reward).
