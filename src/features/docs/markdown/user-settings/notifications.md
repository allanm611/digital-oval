# Notifications

## Overview

Notification settings allow you to control when and how you receive updates about important platform events, including campaign status changes, offer approvals, segment updates, system alerts, and other activities relevant to your work.

## Accessing Notification Settings

**Step 1: Open User Menu**
- Click your **profile icon** in the top-right corner
- A dropdown menu appears

**Step 2: Navigate to Notifications**
- Click on **"Settings"**
- Go to **"Notifications"** section
- OR click **"Preferences"** in notification bell menu

**Route:** `/dashboard/user-settings/notifications`

---

## Notification Preferences Overview

You can customize your notification settings to control:

- **Which events trigger notifications**
- **How you receive notifications** (channels)
- **When you receive notifications** (frequency, do-not-disturb hours)
- **Which notification types to enable/disable**

## Notification Channels

### In-Platform Notifications

**How They Work:**
- Notifications appear in the notification bell icon (top-right)
- Bell shows red badge with unread count
- Click bell to view notification center
- Notifications display with timestamp

**Features:**
- **Notification Center** - View recent notifications
- **Mark as Read** - Individual or bulk mark as read
- **Archive** - Move old notifications to archive
- **Search** - Find notifications by content
- **Filter** - Filter by notification type

**Best For:**
- Time-sensitive alerts
- Real-time updates
- Quick access without email

### Email Notifications

**How They Work:**
- Notifications sent to your registered email
- Subject line summarizes the update
- Email body includes details and action links
- Can directly access item from email

**Features:**
- **Direct Links** - Click to go directly to item in platform
- **Action Buttons** - Approve/reject directly from email
- **HTML Formatting** - Professional, easy-to-read formatting
- **Summary Information** - Key details without login

**Email Address:**
- Notifications sent to email in your profile
- Update email in [My Profile](/documentation/my-profile)
- Verify new email before changes apply

**Best For:**
- Important notifications you might miss
- Offline access to information
- Batch daily/weekly digests

### SMS Notifications (if available)

**How They Work:**
- Critical alerts sent as text messages
- Reserved for high-priority items only
- Sent to phone number in profile
- Immediate delivery

**Best For:**
- Critical system alerts
- Emergency notifications only
- Time-critical approvals

### Slack/Teams Integration (if available)

**How They Work:**
- Notifications sent to Slack or Teams channel
- Can be direct message or channel post
- Include links to platform items
- Integrated into existing workflows

**Setup:**
1. Connect Slack/Teams in integrations
2. Select which notifications to send
3. Choose channel/DM preference
4. Enable integration

## Notification Frequency

### Real-Time Notifications

**Immediate delivery as events occur**

- Notifications sent instantly
- Best for critical items
- Can be overwhelming if too many
- Use for important notifications only

**Best For:**
- Campaign launch/completion
- Approval requests
- System alerts
- Critical errors

### Daily Digest

**Single daily summary of all notifications**

**How It Works:**
1. Notifications collected throughout the day
2. Sent once per day (default time: 9 AM)
3. Organized by notification type
4. Summarizes key information

**Customize Time:**
1. Go to Notification settings
2. Find "Daily Digest"
3. Set delivery time
4. Select timezone

**Best For:**
- Reduce notification volume
- Weekly/bi-weekly review
- Campaign performance summaries
- Regular status updates

### Weekly Digest

**Single weekly summary of all notifications**

**How It Works:**
1. Notifications collected for entire week
2. Sent once per week (default: Monday 9 AM)
3. High-level summary of activities
4. Trends and insights included

**Customize Day &amp; Time:**
1. Go to Notification settings
2. Find "Weekly Digest"
3. Select delivery day
4. Set delivery time
5. Select timezone

**Best For:**
- High-volume users
- Weekly management reviews
- Executive summaries
- Reducing email clutter

### No Notifications

**Disable notifications completely**

- No notifications sent for that type
- Still appear in-platform
- Can change anytime
- Critical alerts may override

## Do Not Disturb Settings

### Enable Do Not Disturb

**Set DND Hours**

1. Go to Notification Settings
2. Find "Do Not Disturb" section
3. Toggle "Enable Do Not Disturb"
4. Set start time
5. Set end time
6. Select days (weekdays, weekends, all days)

**Example:**
- Start: 6:00 PM
- End: 8:00 AM
- Days: Weekdays (Mon-Fri)
- Result: No notifications weekday evenings

### What Happens During DND

**Notification Handling:**
- Notifications are queued (not sent immediately)
- Delivered after DND period ends
- Critical alerts may be exceptions
- In-platform notifications still available in bell

**Notification Delivery After DND:**
- Accumulated notifications sent at end time
- Batched as digest (not individual)
- Summary format for efficiency
- Complete history still available

### Override DND

**Send Urgent Notification During DND:**
- Some critical alerts ignore DND
- System errors/outages always sent
- Security alerts always sent
- Approval urgent requests may override

**Manual Override:**
- Temporarily disable DND
- Go to Notification Center
- Click "Disable DND Until..."
- Select duration (1 hour, rest of day, etc.)

## Notification History

### View Your Notification History

**Access History:**
1. Click notification bell icon
2. Scroll to bottom of notification center
3. Click "View All Notifications"
4. History page shows all notifications

**Notification History Features:**
- Shows notifications from past 30 days (default)
- Search by item name, type, or content
- Filter by notification type
- Filter by read/unread status
- Sort by date, type, etc.

**Export Notifications:**
1. Open notification history
2. Select notifications (or select all)
3. Click "Export"
4. Choose format (CSV, JSON)
5. File downloads

### Archive Old Notifications

**Archive Individual Notification:**
- In notification center, click archive icon
- Notification moved to archive
- No longer in recent list
- Still searchable in history

**Archive Multiple Notifications:**
1. Open notification history
2. Select notifications to archive
3. Click "Archive Selected"
4. Notifications moved

**Archive All Old Notifications:**
1. Go to Notification Settings
2. Click "Archive Notifications Older Than..."
3. Select date threshold (30 days, 90 days, etc.)
4. Confirm archival

## Notification Tips &amp; Best Practices

### For Regular Users

**Recommended Settings:**
- Enable campaign and offer notifications (real-time)
- Enable segment notifications (daily digest)
- Set DND hours to avoid off-work notifications
- Enable approval notifications (real-time)

**Benefits:**
- Stay informed of important updates
- Not overwhelmed by notifications
- Respect work-life balance
- Quick action on approvals

### For Managers &amp; Team Leads

**Recommended Settings:**
- Enable most notification types (real-time)
- Enable team member activity alerts
- Enable performance alerts
- Disable less critical notifications
- Set limited DND hours

**Benefits:**
- Stay informed of team activities
- Quick response to issues
- Oversight of campaigns/offers
- Manage team priorities

### For Administrators

**Recommended Settings:**
- Enable all critical system alerts (real-time)
- Enable infrastructure alerts
- Enable user activity logs
- Enable audit trail notifications
- Minimal DND hours for responsiveness

**Benefits:**
- System health monitoring
- Security awareness
- Compliance tracking
- Rapid incident response

### General Best Practices

**Reduce Email Fatigue:**
- Use daily/weekly digests for non-critical items
- Enable real-time only for critical items
- Set appropriate DND hours
- Archive old notifications regularly

**Stay Organized:**
- Check notification center weekly
- Archive old notifications
- Organize by notification type
- Use search to find specific items

**Privacy &amp; Security:**
- Review connected applications
- Disable notifications for unneeded items
- Use email carefully (includes links)
- Be cautious with email forwarding

**Optimize Productivity:**
- Enable urgent notifications (real-time)
- Use daily digest for reviews
- Set DND during focus time
- Review priority notifications first

## Troubleshooting

### Not Receiving Notifications

**Issue: Email notifications not arriving**
- Check email address is correct in profile
- Verify email is not marked as spam
- Check firewall/email filters
- Ensure notification type is enabled
- Contact support if issue persists

**Issue: In-platform notifications not showing**
- Refresh browser
- Check notification preferences
- Verify notification type is enabled
- Clear browser cache
- Try different browser

**Issue: Missing specific notification**
- Check notification settings
- Verify notification type enabled
- Check if notification was filtered
- Search notification history
- Contact administrator

### Too Many Notifications

**Issue: Receiving too many emails**
- Switch to daily/weekly digest for some types
- Disable non-critical notification types
- Use notification filtering
- Set more restrictive DND hours
- Organize by priority

**Issue: In-platform bell constantly showing badges**
- Mark notifications as read in bulk
- Archive old notifications
- Disable notification types you don't need
- Use notification filters
- Adjust notification frequency

### Notification Delays

**Issue: Notifications arriving late**
- Check system status for outages
- Verify email not in spam
- Check DND settings (may be queued)
- Allow time for delivery
- Report to administrator if persistent
