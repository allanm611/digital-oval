# Customers

## Overview

The Customers page is your central hub for managing your customer database. View all customers in a unified table, search and filter by various criteria, and quickly access individual customer profiles for detailed information and management.

---

## Accessing the Customers Page

**Navigation:** Dashboard → Customer 360 → Customers

The page displays customers in a paginated table with search, filters, and action buttons for managing individual records.

---

## Key Features

- **Search Customers** - Find customers by name, phone number, email, or customer ID
- **Filter Results** - Filter by preferred communication channel and customer type
- **Pagination** - Navigate through customer records (20 per page)
- **Create Customers** - Add single customers, bulk import via CSV, or upload files
- **Manage Customers** - View details, edit information, or delete from the system
- **Export Data** - Download your customer list as CSV
