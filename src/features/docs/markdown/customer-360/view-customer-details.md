# View Customer Details

## Overview

View and manage individual customer profiles with complete access to their information, interaction history, preferences, and engagement data. The customer details page provides a unified view of all customer-related data and actions.

---

## Accessing Customer Details

**Navigation:** Dashboard → Customer 360 → Customers → [Click View on customer row]

**Also Accessible From:**
- Click customer name or "View" button from customer list
- From search results
- From segments (view members)

---

## Profile Section

### Customer Information

The profile section displays core customer data:

**Personal Details**
- **Name** - First and last name
- **Phone Number (MSISDN)** - Primary mobile number
- **Email** - Primary email address
- **Alternate Email** - Secondary email (if provided)
- **Alternate Phone Numbers** - Additional mobile numbers

**Account Details**
- **Customer ID** - Unique identifier
- **Account Status** - Active, Inactive, Blocked, or Suspended
- **Created Date** - When customer was added to system
- **Last Updated** - Most recent profile modification
- **Account Age** - Duration as customer

**Classification**
- **Customer Tier** - Value classification (Gold, Silver, Bronze, Standard, etc.)
- **VIP Status** - Whether marked as VIP customer
- **Test Account Flag** - If this is a test account
- **Fraud Flag** - If flagged for suspicious activity

### Personal Demographics

**Information**
- **Gender** - Male, Female, Other, Prefer Not to Say
- **Date of Birth** - For age calculation and targeting
- **Age** - Auto-calculated or provided
- **Language Preference** - Preferred language
- **Timezone** - Local timezone for communications

**Geographic Information**
- **City** - City/municipality
- **Region/State** - Geographic region
- **Postal Code** - Zip/postal code
- **Physical Address** - Full street address
- **Country Code** - ISO country code

## Preferences & Communication

### Communication Preferences

**Channels**
- **Preferred Channel** - Primary channel for communications
- **Email Preference** - Opted in/out of email
- **SMS Preference** - Opted in/out of SMS
- **Push Preference** - Opted in/out of push notifications
- **WhatsApp Preference** - Opted in/out of WhatsApp
- **Other Channels** - USSD, IVR, In-App, etc.

**Communication Settings**
- **Do Not Disturb (DND)** - Quiet hours or days
- **DND Hours** - Specific times to not send messages
- **DND Days** - Weekdays, weekends, or all days
- **Frequency Cap** - Maximum messages per period
- **Opt-in Status** - Overall communication consent

**Subscription**
- **Active Subscriber** - Currently active in system
- **Subscription Date** - When subscription started
- **Last Activity** - Most recent interaction
- **KYC Verified** - Know Your Customer verification status

### Notification Channel Support

Customer supports multiple notification channels:

| Channel | Description | When Used |
|---------|-------------|-----------|
| **SMS** | Text messages | High-priority, immediate delivery |
| **Flash SMS** | Urgent text messages | Alerts, confirmations |
| **Email** | Email messages | Detailed communications, newsletters |
| **WhatsApp** | WhatsApp messaging | Personal, interactive messages |
| **Push** | Mobile push notifications | App-based notifications |
| **USSD** | USSD menu | Feature phone interactions |
| **Interactive USSD** | Menu-based USSD | Feature phone menus |
| **In-App** | In-application messages | Mobile/web app notifications |
| **IVR** | Voice calls | Voice-based communications |

## Segments & Tags

### Customer Segments

View segments customer belongs to:

**Segment List**
- Click on segment name to view segment details
- Shows segment criteria and size
- See when customer was added to segment
- Option to remove from segment

**Add to New Segment**
1\. Click **Add to Segment**
2\. Search for segment
3\. Select segment(s) to add
4\. Click **Confirm**
5\. Customer added immediately

**Remove from Segment**
1\. Find segment in list
2\. Click **Remove** or delete icon
3\. Confirm action
4\. Customer removed from segment

### Custom Tags

Apply custom tags for organization:

- **Add Tag** - Create or apply custom tag
- **Remove Tag** - Delete tag from customer
- **Tag Colors** - Visual organization
- **Filtered Search** - Find customers by tag

## Campaign Participation History

### Campaign History Table

View all campaigns customer has participated in:

**Columns:**
- **Campaign Name** - Name of campaign
- **Campaign Type** - Type of campaign (Broadcast, A/B Test, etc.)
- **Send Date** - When message was sent
- **Channel** - Delivery channel used (SMS, Email, etc.)
- **Status** - Sent, Delivered, Failed
- **Engagement** - Customer interaction (Opened, Clicked, etc.)

### Campaign Details

For each campaign, see:
- **Sent Date/Time** - When message was delivered
- **Channel Used** - Which channel delivered message
- **Message Content** - If available (truncated)
- **Delivery Status** - Sent, Delivered, Failed, Undelivered
- **Engagement Metrics:**
  - Opened (for email)
  - Clicked (for links)
  - Converted (if applicable)
  - Bounced (if failed)
- **Offer Received** - Offers included in campaign
- **Result/Outcome** - Action customer took

### Filter Campaign History

- **By Date Range** - Filter campaigns by date
- **By Channel** - Filter by SMS, Email, Push, etc.
- **By Status** - Sent, Delivered, Failed, etc.
- **By Campaign Type** - Broadcast, Test, Triggered, etc.

## Communication History

### Message Timeline

Chronological view of all communications sent to customer:

**Information:**
- **Date/Time** - When message was sent
- **Type** - Campaign, Manual, Triggered, Alert
- **Channel** - How it was sent (SMS, Email, etc.)
- **Subject/Preview** - Message content preview
- **Status** - Sent, Delivered, Read, Failed
- **Engagement** - If customer interacted

**View Message Content**
- Click on message to see full content
- View actual message sent to customer
- See dynamic variables used

## Action Buttons

### Edit Customer

Modify customer information and preferences.

**What Can Be Edited:**
- Name (First, Last)
- Email (Primary, Alternate)
- Phone Numbers
- Customer Tier
- Account Status
- Language Preference
- Timezone
- Custom Attributes
- Preferences (Channel, DND, opt-in status)

**Steps:**
1\. Click **Edit** button
2\. Modify fields as needed
3\. Review changes
4\. Click **Save**
5\. Confirmation appears

### Send Communication

Send direct message to customer right now.

**Channel Options:**
- **Email** - Send email message
- **SMS** - Send text message
- **Flash SMS** - Send urgent SMS
- **WhatsApp** - Send WhatsApp message
- **Push** - Send push notification

**Process:**
1\. Click **Send Message**
2\. Select channel
3\. Compose message (or select template)
4\. Add variables if needed
5\. Click **Send**
6\. Confirmation shows delivery status

### Add to Segment

Add customer to segment for targeting.

**Process:**
1\. Click **Add to Segment**
2\. Search for segment
3\. Select one or more segments
4\. Click **Add**
5\. Customer immediately added

### View Campaigns

See detailed view of campaigns customer participated in.

**Shows:**
- Full campaign history
- Detailed engagement metrics
- Message content
- Offers sent
- Links and conversions

### Export Customer Data

Download customer profile as CSV or JSON.

**Includes:**
- Profile information
- Contact details
- Preferences
- Communication history
- Campaign participation
- Segment membership
- Custom attributes

**Format Options:**
- CSV (for spreadsheet)
- JSON (for systems integration)

### Add Note

Add internal notes about the customer (not visible to customer).

**For:**
- Service notes
- Reasons for status changes
- Internal comments
- Follow-up reminders

### Delete Customer

Permanently remove customer from system.

**Warning:** This action is **irreversible** and will:
- Delete all customer data
- Remove from all segments
- Clear campaign history
- Cannot be undone

**Confirmation Required:**
- Must confirm by re-entering customer name or email
- Must acknowledge data loss

## Tips & Best Practices

### Customer Data Management

1\. **Keep Current** - Regularly verify and update information
2\. **Verify Contact** - Ensure phone/email are correct and current
3\. **Complete Profile** - Add demographics for better targeting
4\. **Check Status** - Ensure account status is appropriate
5\. **Review Preferences** - Verify communication preferences match customer wishes

### Privacy & Compliance

1\. **Respect Opt-out** - Honor customer communication preferences
2\. **DND Hours** - Never send during customer DND hours
3\. **Consent** - Verify customer opted-in before communicating
4\. **Data Security** - Protect customer data confidentiality
5\. **Compliance** - Follow regional data protection laws

### Engagement & Targeting

1\. **Monitor Engagement** - Track how customer interacts
2\. **Use History** - Reference past interactions for context
3\. **Segment Appropriately** - Add to relevant segments
4\. **Review Tier** - Ensure tier classification is correct
5\. **Track Results** - Monitor campaign performance for this customer

### Communication

1\. **Personalize** - Use customer data for personalization
2\. **Use Preferred Channel** - Respect preferred communication channel
3\. **Best Timing** - Send during customer's active hours (timezone)
4\. **Frequency** - Don't over-communicate, respect frequency caps
5\. **Relevant Content** - Send targeted, relevant messages

## Common Tasks

### Update Customer Email

1\. Click **Edit**
2\. Change email field
3\. System validates new email
4\. Click **Save**
5\. Email updated

### Change Customer Status

1\. Click **Edit**
2\. Change "Account Status" field
3\. Select new status (Active, Inactive, Blocked, etc.)
4\. Optionally add reason
5\. Click **Save**

### Send SMS to Customer

1\. Click **Send Message**
2\. Select **SMS** channel
3\. Type message
4\. Click **Send**
5\. Shows delivery confirmation

### Add Customer to Segment

1\. Click **Add to Segment**
2\. Search for segment name
3\. Select segment
4\. Click **Add**
5\. Customer added immediately

### View Campaign History

1\. Scroll to **Campaign History** section
2\. See all campaigns sent to customer
3\. Click on campaign for details
4\. View engagement and results

### Change Preferred Channel

1\. Click **Edit**
2\. Change **Preferred Channel**
3\. Select new channel (SMS, Email, WhatsApp, etc.)
4\. Click **Save**
5\. Future messages use new channel
