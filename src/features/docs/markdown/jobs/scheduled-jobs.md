# Scheduled Jobs

## Overview

Scheduled Jobs are automated tasks that execute workflows. Create and manage job definitions, control their execution status, and monitor performance.

---

## Statuses

- **Draft** - Job not yet activated
- **Active** - Job is operational
- **Paused** - Job temporarily stopped
- **Archived** - Job no longer in use

---

## Filters

- **Status** - Filter by job status (active, paused, draft, archived)
- **Search** - Search by job name or code
- **Job Type** - Filter by job type
- **Owner** - Filter by job owner
- **Tags** - Filter by tags
- **Schedule Type** - Filter by schedule type
- **Connection Profile** - Filter by connection profile
- **Tenant** - Filter by tenant
- **Active Jobs Only** - Show only active jobs

---

## Statistics

- **Total Jobs** - Total number of scheduled jobs
- **Active Jobs** - Number of active jobs
- **Draft Jobs** - Number of draft jobs

---

## Actions

**Individual Job Actions:**
- **View** - See job details
- **Edit** - Modify job settings
- **Execute Now** - Trigger immediate execution
- **Pause** - Stop job execution
- **Resume** - Resume paused job
- **Archive** - Archive job
- **Delete** - Remove job
- **Clone** - Duplicate job configuration

**Batch Actions:**
- **Pause/Resume** - Bulk pause or resume multiple jobs
- **Delete** - Delete multiple jobs
