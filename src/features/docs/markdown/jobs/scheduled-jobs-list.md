# Scheduled Jobs List

## Overview

View and manage all scheduled jobs in the system.

---

## Statistics Cards

- **Total Jobs** - Count of all scheduled jobs
- **Active Jobs** - Currently enabled jobs
- **Draft Jobs** - Jobs not yet activated

---

## Filters

- **Search** - Search by job name or code
- **Status** - Filter by status (all, active, paused, draft, archived)
- **Job Type** - Filter by job type
- **Owner** - Filter by job owner
- **Tags** - Filter by tags
- **Schedule Type** - Filter by schedule type
- **Connection Profile** - Filter by connection profile
- **Tenant** - Filter by tenant
- **Job Code** - Search by exact job code
- **Active Jobs Only** - Toggle to show only active jobs

---

## Actions

**Individual Job Actions:**
- **View** - See job details
- **Edit** - Modify job settings
- **Execute Now** - Trigger immediate execution
- **Pause** - Stop job execution
- **Resume** - Resume paused job
- **Archive** - Archive job
- **Delete** - Remove job
- **Clone** - Duplicate job
- **View Analytics** - Performance metrics

**Batch Actions:**
- **Pause** - Pause multiple jobs
- **Resume** - Resume multiple jobs
- **Delete** - Delete multiple jobs
