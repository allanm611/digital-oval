# Step Executions

Step Executions tracks runtime outcomes for individual workflow steps.

This feature gives step-level visibility when a full job execution has mixed results.

## What You Manage Here

- per-step status and timing
- step-level failure context
- resource usage at step granularity
- linkage back to parent job execution
