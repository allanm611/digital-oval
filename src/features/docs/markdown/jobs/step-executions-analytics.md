# Step Executions Analytics

Step Executions Analytics tracks step-level runtime quality and performance trends.

## Typical Metrics

- step status distribution
- step duration trend and outliers
- retry and timeout concentration by step type
- failure hot spots by job/workflow

## How To Use It

- find the exact step categories driving failures
- validate improvements after step-action updates
- tune retry and timeout at the step level
