# Step Executions List

Step Executions List is the table view for step-level runtime records.

## Common Table Fields

- **Step Name / Step Code**
- **Job Execution ID**
- **Status**
- **Started At / Completed At**
- **Duration**
- **Error Context**

## Filters

Common filters include status, step type/code, date range, and parent job execution.

## Actions

- **View** details for a step execution
- additional retry/abort actions where state and permissions allow
