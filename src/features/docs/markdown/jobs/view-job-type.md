# View Job Type Details

## Overview

The Job Type Details page displays complete information about a specific job type.

## Page Layout

### Header
- **Type Name** - Display name
- **Type Code** - Unique identifier
- **Job Count** - Number of jobs using this type

## Information Sections

### Basic Information

**Name**
- Display name of the type

**Code**
- Unique type identifier

**Description**
- Detailed explanation of type purpose

### Statistics

**Total Jobs**
- Count of jobs using this type

**Created**
- Date and time type was created

## Actions

### Edit
- **Function:** Open edit form
- **Allows:** Modify type name and description

### View Jobs
- **Function:** See jobs using this type
- **Shows:** Filtered job list

### Delete
- **Function:** Remove type
- **Note:** Only if no jobs use it
- **Requires:** Confirmation

### Create Job
- **Function:** Create new job of this type
- **Action:** Opens create job form

## Common Tasks

### View Jobs of Type
1. Click "View Jobs" button
2. See all jobs using this type
3. Filter and analyze by job characteristics

### Edit Type Description
1. Click "Edit" button
2. Update description
3. Save changes

### Delete Unused Type
1. Verify no jobs use type
2. Click "Delete" button
3. Confirm deletion
4. Type is removed
