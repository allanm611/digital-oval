# View Step Execution

Step Execution Details shows runtime diagnostics for one workflow step execution.

## What You See

- execution status and timestamps
- duration and retry outcomes
- error message/code context when failed
- step action metadata
- parent job execution linkage

## Why This Page Matters

Use this page when a job fails and you need to isolate exactly which step caused the issue.
