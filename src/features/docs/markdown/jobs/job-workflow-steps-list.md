# Job Workflow Steps List

Job Workflow Steps List is the operational table for step definitions.

## Table Fields

- Step Name / Code
- Job ID
- Step Type
- Step Order
- On Failure Action
- Is Critical
- Is Parallel
- Retry Count
- Active State

## Filters

Search by name/code and filter by step type, job, or failure behavior.

## Actions

- Create
- View
- Edit
- Delete
- clone/validate/execute actions where enabled
