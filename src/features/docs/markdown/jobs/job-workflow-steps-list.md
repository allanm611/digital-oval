# Job Workflow Steps List

## Overview

View and manage all workflow steps for a job.

---

## Statistics Cards

- **Total Steps** - Count of all steps
- **Active Steps** - Currently enabled steps
- **Critical Steps** - Steps marked as critical
- **Steps with Retry** - Steps with retry configured
- **Steps with Validation** - Steps with validation enabled
- **Parallel Groups** - Number of parallel execution groups

---

## Filters

- **Search** - Search by step name
- **Step Type** - Filter by step type (sql, stored_proc, api_call, python_script, node_js_script, shell_script, file_transfer, data_validation, notification, wait)
- **Job ID** - Filter by job

---

## Actions

**Individual Step Actions:**
- **View** - See step details
- **Edit** - Modify step settings
- **Clone** - Duplicate step
- **Delete** - Remove step
- **Validate** - Test step configuration

**Batch Actions:**
- **Pause/Resume** - Bulk pause or resume steps
- **Reorder** - Change execution sequence
- **Update** - Batch update configuration
- **Delete All** - Delete all steps for a job
