# Edit Scheduled Job

## Overview

Modify an existing scheduled job.

---

## Editable Fields

- **Name** - Job display name
- **Type** - Job type
- **Description** - Job description

---

## Non-Editable Fields

- **Code** - Cannot be changed after creation

---

## Actions

- **Save** - Update job
- **Cancel** - Discard changes
