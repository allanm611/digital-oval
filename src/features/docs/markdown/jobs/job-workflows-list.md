# Job Workflows List

## Overview

The Job Workflows List displays all configured workflows. From this page, you can manage workflow definitions, view statistics, and configure job procedures.

## Page Layout

### Statistics Cards
- Total Workflows - Count of all workflows
- Active Workflows - Currently enabled
- Draft Workflows - Being configured
- Workflows by Type - Distribution by type

### Workflows Table

Each workflow entry displays:
- Workflow Name - Display name
- Workflow Code - Unique identifier
- Workflow Type - Category/type
- Status - Active/Draft/Paused/Archived
- Step Count - Number of steps
- Created - When created
- Modified - Last modification
- Action Menu - Quick actions

## Filtering

### Search
- Type: Text input
- Function: Search by workflow name or code
- Real-time results update

### Status Filter
- Active - Currently enabled
- Draft - Being configured
- Paused - Temporarily inactive
- Archived - No longer in use

### Workflow Type Filter
- Filter by type category
- ETL, Reporting, Integration, Maintenance, etc.

### Active Only Filter
- Toggle to show only active workflows

### Sort Options
- Name (A-Z)
- Status
- Workflow Type
- Step Count (Most/Least)
- Created Date (Newest/Oldest)
- Modified Date (Newest/Oldest)

## Actions

### Individual Workflow Actions

Click menu icon (⋮):

**View Details**
- Open workflow details page
- See full configuration
- View all steps

**Edit**
- Modify workflow settings
- Update name and description
- Change type

**Manage Steps**
- Add/remove/reorder steps
- Configure step execution
- View step details

**Clone**
- Duplicate workflow
- Create similar workflows quickly
- Modify duplicated workflow

**Activate/Deactivate**
- Toggle workflow status
- Enable/disable without deleting

**Archive**
- Mark as no longer in use
- Retained for history

**Delete**
- Permanently remove workflow
- Confirmation required

### Bulk Actions

Select multiple workflows to:
- Activate Multiple - Enable several workflows
- Deactivate Multiple - Disable several workflows
- Archive Multiple - Archive several workflows
- Delete Multiple - Remove multiple workflows

## Selection Mode

Header Checkbox - Select all visible
Individual Checkboxes - Select specific workflows

## Pagination

- 20 workflows per page
- Navigate between pages
- Total count displayed

## Common Tasks

### Create New Workflow
1. Click "Create Workflow" button
2. Fill in workflow details
3. Add steps to workflow
4. Save workflow

### View Workflow Configuration
1. Click workflow name
2. See all details
3. Review all steps
4. Check configuration

### Edit Workflow Details
1. Find workflow
2. Click "Edit"
3. Modify name/description/type
4. Save changes

### Manage Workflow Steps
1. Open workflow
2. Click "Manage Steps"
3. Add/remove/reorder steps
4. Configure step properties

### Clone Workflow
1. Find workflow to clone
2. Click "Clone"
3. Provide new name
4. Modify if needed
5. Save new workflow

### Deactivate Workflow
1. Find workflow
2. Click "Deactivate"
3. Workflow no longer executes
4. Can be reactivated later

### Archive Old Workflow
1. Find unused workflow
2. Click "Archive"
3. Workflow removed from active list
4. Retained for history
