# Jobs

## Overview

Jobs (Connect) manages automation, scheduling, and orchestration of business processes. Set up automated workflows, scheduled jobs, and integrations to manage data flows and campaign execution across your organization without manual intervention.

---

## What You Can Do

### [Scheduled Jobs](/documentation/jobs/scheduled-jobs)

Create and manage automated tasks that run according to schedules or triggers. Set up jobs to run manually, on a schedule, or based on events and dependencies.

### [Create Scheduled Job](/documentation/jobs/create-scheduled-job)

Set up a new automated job with scheduling options, execution parameters, and error handling configuration.

### [Edit Scheduled Job](/documentation/jobs/edit-scheduled-job)

Modify job configuration, schedule, parameters, and dependencies.

### [View Scheduled Job](/documentation/jobs/view-scheduled-job)

Access job details including configuration, execution history, and performance metrics.

### [Job Workflows](/documentation/jobs/job-workflows)

Understand workflow orchestration. Workflows are sequences of steps that define complex job procedures, handling dependencies and error management.

### [Create Job Workflow](/documentation/jobs/create-job-workflow)

Build new workflows with multiple steps, dependencies, and execution logic.

### [Job Workflow Steps](/documentation/jobs/job-workflow-steps)

Configure individual steps within a workflow. Define step actions, validation, error handling, and dependencies.

### [Job Dependencies](/documentation/jobs/job-dependencies)

Set up relationships between jobs. Configure how jobs trigger each other and manage dependencies.

### [Job Executions](/documentation/jobs/job-executions)

Monitor job execution history and performance. Track successful runs, failures, and execution metrics.

---

## Quick Start

**New to jobs?**

1. Go to [Scheduled Jobs](/documentation/jobs/scheduled-jobs) to see existing automated tasks
2. Follow [Create Scheduled Job](/documentation/jobs/create-scheduled-job) to set up a new job
3. View [Job Workflows](/documentation/jobs/job-workflows) to understand automation orchestration
4. Check [Job Executions](/documentation/jobs/job-executions) to monitor job performance
5. Set up [Job Dependencies](/documentation/jobs/job-dependencies) to create multi-job workflows
