# Overall Dashboard Performance

## Overview

The Overall Dashboard Performance provides a comprehensive view of your entire customer engagement platform's health and key metrics. This dashboard aggregates data from campaigns, customer profiles, offers, and delivery channels to give executives and managers a bird's-eye view of performance.

## Key Sections

### Hero Metrics (Summary KPIs)

The top section displays critical business metrics at a glance:

**Customer Metrics**
- **Active Customers:** Number of currently active customers
- **New Customers:** Customers acquired in selected period
- **Churn Rate:** Percentage of customers lost (%)
- **Engagement Score:** Overall customer engagement (0-100)

**Revenue Metrics**
- **Total Revenue:** Revenue generated in period
- **Average Customer Lifetime Value (CLV):** Average value per customer
- **Average Order Value (AOV):** Average transaction value
- **Purchase Frequency:** Average purchases per customer per period

**Campaign Metrics**
- **Active Campaigns:** Number of running campaigns
- **Total Reach:** Combined audience reach across campaigns
- **Conversion Rate:** Overall campaign conversion (%)
- **Click-Through Rate (CTR):** Campaign engagement (%)

**Delivery Metrics**
- **Messages Sent:** Total messages across channels
- **Delivery Rate:** Percentage successfully delivered (%)
- **Open Rate:** Email open rate (%)
- **SMS Delivery Success:** SMS delivery success rate (%)

### Performance Trends

**Multi-line Chart:** Track key metrics over time
- **Metrics Displayed:**
  - Active customers trend
  - Revenue trend
  - Engagement score trend
  - Conversion rate trend

- **Time Period Options:**
  - 7 days (daily view)
  - 30 days (weekly view)
  - 90 days (monthly view)

**Interpretation:**
- **Uptrend:** Improving performance
- **Downtrend:** Declining performance
- **Flat line:** Stable metrics

## Troubleshooting

### Missing Data
- **"No data for selected period"** - Check if date range has activity
- **"Chart not loading"** - Refresh page or clear filters
- **"Metrics show 0"** - Verify filter selections and data availability

### Inaccurate Numbers
- **"Numbers don't match"** - Check filter combinations
- **"Discrepancy with other reports"** - Verify same date range
- **"Missing campaigns"** - Check campaign status filters

### Performance Issues
- **"Dashboard loads slowly"** - Reduce date range or filters
- **"Charts not rendering"** - Refresh page or clear cache
- **"Export fails"** - Try smaller date range first
