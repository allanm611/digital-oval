# KPI List

## Overview

View all Key Performance Indicators. Search, filter by category, and view KPI details.

---

## Statistics Cards

- **Total KPIs** - Count of all KPIs
- **System Events** - Number of system event KPIs
- **Usage Metrics** - Number of usage metric KPIs
- **Revenue Metrics** - Number of revenue metric KPIs

---

## Search and Filter

### Search
- Search by KPI name
- Real-time results

### Category Filter
- System Event
- Usage Metric
- Revenue Metric
- All Categories
