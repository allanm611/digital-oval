# Connection Profiles List

## Overview

Displays all configured connections to external data sources. Search, filter, and manage connection profiles.

---

## Statistics Cards

- **Total Profiles** - Count of all profiles
- **Active Profiles** - Enabled profiles
- **Profiles with PII** - Contains personal data
- **Health Enabled** - Profiles with health checks

---

## Filtering Profiles

### Search
- Search by profile name or code
- Real-time results

### Connection Type
- Database
- API
- SFTP
- FTP
- S3
- Azure Blob
- Kafka
- Webhook

### Environment
- development
- staging
- production

### Classification
- public
- internal
- confidential
- restricted

### Status
- Active
- Inactive
- Expired

### PII
- With PII
- Without PII

### Health Check
- Enabled
- Disabled

---

## Profile List

Each entry shows:
- Profile Name, Code
- Connection Type
- Environment, Status
- Classification, PII indicator
- Health Status

---

## Actions

### Individual Profile Actions

**View Details**
- Open profile details

**Edit**
- Modify profile settings

**Test Connection**
- Verify connectivity

**Deactivate/Activate**
- Toggle status

**Delete**
- Remove profile

### Bulk Actions

- **Activate Multiple**
- **Deactivate Multiple**
- **Delete Multiple**

---

## Pagination

- 20 profiles per page
- Navigate between pages
