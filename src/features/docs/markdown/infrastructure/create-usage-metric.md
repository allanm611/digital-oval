# Create Usage Metric

Use this page to define usage-focused KPI records.

![Usage Metric - Basic Information](/img/infrastructure/usagemetricdetailpagebasicinfo.png)
![Usage Metric - Data Source and Operators](/img/infrastructure/usagemetricdetaildatasourceand%20operators.png)

## Required Inputs

- Name
- Description
- Field Type
- Category
- Operators
- Source Table
- Data Source
- Frequency

## Practical Notes

Usage metrics are commonly used in segmentation conditions, so choose operators and frequency that match how segments are evaluated.
