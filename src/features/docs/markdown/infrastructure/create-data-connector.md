# Create Data Connector

Create Data Connector opens a form (or modal) used to register a new connector definition.

## Common Required Fields

- **Name**: connector display label
- **Type-specific configuration values** required by the selected connector type

## Optional Fields

- **Description**: operational context for the platform
- **Active Status**: whether connector should be immediately available

## What The Fields Mean

- **Name** should be clear enough for operators to identify quickly.
- **Connector type settings** define technical access behavior for that source type.
- **Status** controls whether the connector can be used in active flows.

## Save Behavior

Required values must be completed before save. After creation, the connector appears in Data Connectors List.
