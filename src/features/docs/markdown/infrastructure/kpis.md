# KPIs

## Overview

Key Performance Indicators (KPIs) track measurable business metrics. The system supports three KPI categories: System Events, Usage Metrics, and Revenue Metrics.

---

## KPI Categories

### System Events
KPIs based on system events

### Usage Metrics
KPIs measuring usage patterns

### Revenue Metrics
KPIs tracking revenue

---

## Available Actions

- **View** - See KPI details
- **Search** - Find KPIs by name
- **Filter** - Filter by category
