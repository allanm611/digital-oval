# View Connection Profile Details

## Overview

View complete configuration and status for a specific connection profile.

---

## Profile Information

Displays all profile details:
- Name, Code
- Status (Active/Inactive/Expired)
- Connection Type, Load Strategy
- Environment
- Server
- Batch Size, Parallel Threads
- Min/Max Pool Size
- Connection & Idle Timeouts
- Max Retries, Retry Backoff Multiplier
- Circuit Breaker Threshold
- Database Type, Database Name
- Sync Column Name, Type
- Health Check settings and status
- Data Classification, PII indicator
- GDPR Applicable status
- Valid From/To dates
- Metadata
- Created/Updated timestamps

---

## Actions

### Edit
- Modify profile settings

### Activate/Deactivate
- Toggle profile operational status

### Test Connection
- Verify connectivity

### Delete
- Remove profile
