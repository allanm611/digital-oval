# ETL (Extract, Transform, Load)

## Overview

ETL manages data file ingestion. Track imported files, control fetching, and monitor processing.

---

## Key Features

### File Registry
- Track all imported files
- Monitor processing status
- Support for CDR and TDR categories

### Fetch Controls
- Fetch files immediately
- Fetch files by time slot
- Fetch files within date range
- Force reprocessing

### Analytics
- File processing statistics
- Category distribution
- Processing duration metrics

---

## File Categories

### CDR
Call Detail Records

### TDR
Transaction Detail Records

---

## File Statuses

- **Pending** - Waiting to process
- **Processing** - Currently processing
- **Completed** - Successfully processed
- **Failed** - Processing failed
- **Skipped** - Skipped (duplicate/invalid)
